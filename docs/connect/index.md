# 2부 개요 — 연결이 왜 필요한가

> 1부에서 만난 에이전트가 **내 컴퓨터 밖의 자료와 도구**까지 다루게 하는 이야기입니다. 새로운 단계가 아니라, 이미 도달한 자리에서 **손이 닿는 범위**를 넓히는 축입니다.

1부는 AI에게 무엇을 어떻게 맡길지를 다뤘습니다. 그런데 실제로 일에 쓰는 자료는 대부분 내 컴퓨터 안에 있지 않습니다. 이슈와 코드 문서는 GitHub에, 회의록·규정·기획서는 Confluence에, 업무 요청은 Jira에 흩어져 있죠. 매번 필요한 부분을 찾아 복사해 붙여넣는 대신, **AI가 그 자료를 직접 읽고 쓰게 잇는 것**이 2부의 주제입니다.

잇는 방법은 두 갈래입니다. 이미 준비된 목록에서 고르고 승인만 하면 되는 [기본 커넥터](connectors.md)와, 그 목록에 없는 것을 직접 등록하는 [MCP 서버](mcp-servers.md)입니다. 용어의 정의는 1부 [기본 용어와 범위 — 외부 컨텍스트](../basics.md#external-context)에 있으니, 여기서는 **어떤 상황에 무엇을 고르고 무엇을 조심해야 하는지**를 이어서 살펴봅니다.
