## 1. 열거 방식

장(H1) 하나를 행 하나로 세운다. #55의 docs 커밋 20건은 장 단위 대조를 대신하지 않고 보조 입력으로만 쓰며, 부록 B에 커밋 축 매핑을 따로 둔다 (spec 전제 12(a)).

`근거·대응 docs` 열의 docs 위치는 **헤딩 앵커** 기준이다. #55 커밋 20건으로 docs 줄 번호가 전부 어긋나 노트 부록 B-1의 줄 번호를 그대로 쓸 수 없기 때문이다 (spec 전제 1). 앵커가 없는 절은 헤딩 문구를 적었다.
