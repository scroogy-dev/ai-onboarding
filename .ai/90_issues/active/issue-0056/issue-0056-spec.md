# Issue #56 스펙 ― slides docs 전수 동기화 (드리프트 정정·누락 절 편입, #55 후속)

## 목표 (Goal)

#55로 확정된 `docs/`를 기준으로 `slides/slides.md` 93장을 전수 대조해, 두 표면이 같은 주제를 다르게 말하는 곳을 0건으로 만들고, 슬라이드에 없는 docs 절 중 고른 것을 편입하며, 슬라이드에만 있는 내용은 docs 편입 또는 삭제로 처리해 ADR-0002의 단방향 파생 상태를 회복한다.

### R5: 93장 전수 점검표

- [ ] [D] 점검표 행 수가 덱 장수(H1 수)와 같고, 모든 행의 판정이 반영 또는 해당 없음이다 (누락·미판정 0건). 착수 시점 점검표가 없어 실패하는 상태에서 시작한다.
  <details>
  <summary>검증 명령 ― 출력 0건이면 통과</summary>

  ```bash
  F=.ai/90_issues/active/issue-0056/issue-0056-sync-check.md
  N=$(grep -cE '^# ' slides/slides.md)
  R=$(grep -cE '^\| [0-9]+ \| ' "$F" 2>/dev/null); R=${R:-0}
  [ "$R" -eq "$N" ] || echo "위반: 점검표 ${R}행, 덱 ${N}장"
  grep -E '^\| [0-9]+ \| ' "$F" 2>/dev/null \
    | awk -F'|' '{ gsub(/^ +| +$/, "", $4); if ($4 !~ /^(반영|해당 없음)$/) print "위반: " $0 }'
  ```

  - 설계 주의: 점검표 열 순서는 `| # | 슬라이드 제목 | 판정 | 근거·대응 docs |`로 고정한다 (awk `$4`가 판정 열). 덱은 장마다 H1 1개를 두는 관례라 `^# ` 수가 장수다. 새로 만드는 장에도 H1을 둔다. 「누락」은 작업 중 임시 값이고 완료 시 남으면 이 게이트가 잡는다. 파일이 없으면 `R`이 0이 되어 행 수 불일치로 실패한다.
  </details>
