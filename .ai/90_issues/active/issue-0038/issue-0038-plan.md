### Task 1: 오버플로우 케이스 인벤토리

- [x] 완료
- **목표**: 「식별된 케이스」 외에 추가로 화면 밖으로 넘치는 페이지 목록을 확보한다.
- **작업 내용**:
  1. `slides/` 구조 및 진입 파일(예: `slides/slides.md`) 확인
  2. Slidev 미리보기(`npm run dev` 등) 또는 빌드 산출물로 각 페이지를 viewport(16:9 기본) 기준으로 확인
  3. 오버플로우가 발생하는 페이지를 `slides/파일:슬라이드번호` 형식으로 「식별된 케이스」 표에 추가하고, 추정 원인(텍스트 과다·이미지·표·코드블록 등)을 함께 기록
- **완료 기준**: 「식별된 케이스」 표가 갱신되어 있고, 추가 발견이 없는 경우 그 사실이 summary에 명시되어 있다.
