- **작업 내용**:
  1. ADR-0005 §3 본문과 ADR-0001 3단계 모델을 재독하며 본 이슈의 "메커니즘 정직 가시화" 방향과의 위상 차이를 정리
  2. 비교표가 다루는 3종(1회성 프롬프트 · 에이전트 스킬 · 애플리케이션)이 ADR-0001 3단계 모델과 어떻게 매핑되는지 확인 (예: 챗봇 1회성 ↔ 1회성 프롬프트, 프롬프트 재활용 ↔ 에이전트 스킬, 에이전트 ↔ 애플리케이션? 또는 다른 매핑?)
  3. 처리 방향 결정:
     - (A) ADR-0005에 "Issue #40 후속 변경" 노트 추가 — §3 원칙은 유지하되 비교표 한정 예외 명시
     - (B) 신규 ADR 작성 — 본 이슈의 결정성 가시화가 ADR-0005를 부분 대체
     - (C) ADR 변경 없음 — 비교표는 ADR-0005 §3와 양립 가능 (결과형 표현으로만 비교표 구성)
- **완료 기준**: 결정 사항이 summary Task 1에 기록되어 있고, 후속 ADR 작업 필요 여부가 명확하다
