### Task 3: 줄표 문자 전환 ― U+2014 → U+2015 전 범위 일괄

- [x] 완료
- **목표**: 발행물 전체와 이 이슈 작업 문서의 줄표 문자를 U+2015로 통일한다. 이후 모든 산문 정리·검증이 한 문자 기준으로 서게 하는 선행 작업이다.
- **선행 근거**: 산문 정리(Task 5·6)보다 **앞**에 둔다. 뒤에 두면 labs·slides를 정리하는 동안 두 문자가 공존해, 어느 파일이 어느 상태인지 매번 따져야 한다. 앞에 두면 전환 이후 등장하는 줄표는 전부 U+2015 하나다.
- **작업 내용**:
  1. spec 「포함 (In)」의 *문자 통일 대상* 전체에서 U+2014를 U+2015로 치환한다. 대상은 `docs/**/*.md`(connect 3페이지 포함)·`labs/**/*.md`·`labs/**/*.html`·`slides/slides.md`·`mkdocs.yml`과 이 이슈 작업 문서 3종이다.
  2. 치환은 단순 전량 치환이다 ― 이 시점의 U+2014는 부제·기호·산문 자리에 두루 있지만, 산문 자리는 Task 5·6에서 어차피 없애므로 자리를 가릴 필요가 없다.
  3. `issue-workflow.md`는 제외한다 (스킬 템플릿 사본).
  4. 치환 후 `mkdocs build --strict`와 Slidev 빌드로 렌더링 회귀가 없는지 확인하고, 사이트에서 U+2015 글리프가 정상 표시되는지 육안 확인한다.
- **완료 기준**:
  - [D] 대상 전체에서 U+2014 0건  (검증: spec 완료의 정의 1번 `[D]`의 명령 재실행)
  - [D] 치환 전후로 대시 계열 총량이 보존됨 ― U+2014 건수만큼 U+2015가 늘고, 그 외 문자는 변동 없음
    <details>
    <summary>검증 명령 ― repo 루트에서 실행, 「일치」가 출력되면 통과</summary>

    ```bash
    EM=$(printf '\xe2\x80\x94'); HB=$(printf '\xe2\x80\x95')
    FILES="$(find docs labs -name '*.md' -o -name '*.html' | sort) slides/slides.md mkdocs.yml $(find .ai/90_issues/active/issue-0050 -name '*.md' | sort)"
    before=562   # 착수 시점 U+2014 실측치(발행물 562건). 작업 문서분은 치환 직전에 다시 센다
    now=$(cat $FILES | grep -o "$HB" | wc -l | tr -d ' ')
    echo "U+2015 현재 ${now}건 / 전환 전 U+2014 ${before}건 + 기존 U+2015 0건"
    [ "$now" -ge "$before" ] && echo "일치(하한 충족)" || echo "위반: 치환 누락"
    ```

    - 설계 주의: 착수 시점 U+2015가 0건이므로 전환 후 U+2015 건수는 전환 전 U+2014 건수 이상이어야 한다. 등호가 아니라 하한으로 두는 이유는 작업 문서 3종의 U+2014가 이 이슈 진행 중 계속 늘기 때문이다 ― 상한을 고정하면 spec을 한 줄 고칠 때마다 기준이 깨진다.
    - 이 항목은 "0건" 게이트만으로는 **문자를 지워 버려도 통과**하는 구멍을 막는다. 치환이 아니라 삭제로 통과시키는 경로를 차단하는 것이 목적이다.
    - **판정 시점은 Task 3 직후로 한정된다**(Task 5 확인). 이 이슈는 Task 5·6에서 산문 줄표를 실제로 없애므로 그 뒤에는 총량이 하한 아래로 내려가는 것이 정상이다. 착수 시점 562건 → Task 3 직후 667건 → Task 6 종료 시점 342건. 나중에 이 명령을 재실행하면 위반으로 나오지만 결함이 아니며, 이 시점 이후의 합/불은 spec 완료의 정의 1·2·3번 게이트가 판정한다.
    </details>
  - [D] `.venv/bin/mkdocs build --strict` 종료 코드 0
  - [D] `(cd slides && npm run build)` 종료 코드 0
