# Issue #50 스펙 — 줄표(—) 과다 정리: 1부·공통 페이지와 labs·slides (쌍점·하위 목록 기준)

## 목표 (Goal)

docs 잔여 페이지와 labs·slides의 본문 산문에서 줄표(—) 과다 사용을 #49 확정 기준(표제 뒤 짧은 부연은 쌍점, 길면 하위 목록·문장 분리)으로 정리하고, 유지 자리의 줄표는 보존한다.

**적용 기준** (이슈 #50 본문과 #49 Task 8에서 확정, 유지 자리·전환 자리 세부는 Task 0에서 확정)

- 표제·라벨 뒤 짧은 부연: 쌍점(:) 또는 문장 분리
- 부연이 길어지면: 부호 대신 하위 목록·문장 분리로 구조화 (쌍점 뒤가 길어지면 앞 문맥이 희석됨)
- 쌍점이 이미 라벨 구분자로 쓰인 자리: 쌍점이 한 줄에 두 번 나오지 않도록 괄호·문장 분리로 처리
- 줄표(—) 유지 자리
    - 제목(H1~H3)·admonition 제목·nav 라벨
    - 링크 라벨(문서 제목을 그대로 반영). 부 명칭 "2부 — 도구·데이터 연결"은 전부 링크 라벨 안에 있어 여기 해당한다
    - 표의 "해당 없음" 기호(`| — |`·`| — (회사가 계약) |`)와 그 기호를 설명하는 범례 행
    - HTML 자산의 `<title>`·HTML/CSS 주석·장식 기호(`— 기억 포인트`)·인용 출처(`— 담당 튜터 이서연`)·페이지 표기(`— 1 / 1 —`)
- 전환 자리 (Task 0에서 확정, 유지 자리와의 경계가 모호했던 것)
    - 표 셀 안의 줄표 전부. 1열의 명칭 라벨("1단계 — 챗봇 사용")도 포함하며, 슬라이드의 `—<br/>`는 `:<br/>`로 바꿔 줄바꿈 구조를 유지한다
    - `labs/` SKILL.md 코드블록 안의 출력 형식 명세와 예시 출력. 형식 명세와 예시 출력은 같은 형태로 맞춰 실습자가 보는 결과물과 어긋나지 않게 한다

## 완료의 정의 (Definition of Done)

> **검증 레벨** — 낮을수록 좋다(자동 검증에 가까움). 기본은 L1, 한 레벨 내릴 때마다 강등 사유를 함께 적는다.
>
> - `[D]`  L1 결정적   — 명령이 합/불을 판정, 사람 판단 없음
> - `[QD]` L2 준결정적 — 다른 AI·기준 체크리스트가 채점
> - `[ND]` L3 비결정적 — 사람이 직접 읽고 판단

- [ ] [D] 마크다운 대상 파일 전부에서 유지 자리(제목·admonition 제목·링크 라벨·표의 해당 없음 기호·범례 행)를 걷어낸 뒤 잔존 줄표 0건
  <details>
  <summary>검증 명령 — repo 루트에서 실행, 출력 0건이면 통과</summary>

  ```bash
  for f in docs/index.md docs/intro.md docs/basics.md docs/labs.md \
           docs/operation-guide.md docs/security-guide.md \
           $(find labs -name '*.md' | sort) slides/slides.md; do
    n=$(sed -E 's/\[[^][]*\]\([^()]*\)//g; s/\|[[:space:]]*—[[:space:]]*/|/g' "$f" \
        | grep -vE '^#{1,6} |^[[:space:]]*(!!!|\?\?\?\+?) ' \
        | grep -vE '^[[:space:]]*(\*\*)?범례(\*\*)?:.*해당 없음' \
        | grep -c '—')
    [ "$n" -gt 0 ] && echo "위반: $f ($n곳)"
  done; true
  ```

  - 설계 주의: `sed` 1식이 인라인 링크(라벨 포함)를 통째로 제거해 링크 라벨 유지 자리를, 2식이 표의 `| — |`·`| — (회사가 계약) |` 셀을 걷어낸다. `grep -v` 1식이 제목 행과 admonition 제목 행을, 2식이 범례 행을 제외한다. nav 라벨은 `mkdocs.yml`에 있어 검사 대상 파일에 없다.
  - 범례 예외(Task 0에서 추가): 표의 "해당 없음" 기호를 설명하는 행이라 줄표가 기호 자체를 지칭한다. 현재 `docs/security-guide.md` 193행·`slides/slides.md` 1760행 2곳에 해당하며, 패턴에 `해당 없음`을 함께 걸어 범례라는 낱말만으로 다른 행이 통째로 빠지는 과소 검출을 막았다.
  - 부 명칭("2부 — 도구·데이터 연결")은 Task 0 실측 결과 전부 링크 라벨 안에 있어 `sed` 1식으로 걷힌다. 산문에 단독 등장하는 사례는 없으므로 별도 예외를 두지 않았다.
  - 표 셀 안 줄표는 Task 0에서 전환 자리로 확정했으므로 예외를 두지 않는다 — `sed` 2식이 걷어내는 것은 셀 전체가 "해당 없음" 기호인 경우로 한정된다.
  - 마지막 `; true`는 루프 마지막 `[ ]` 판정의 종료 코드가 명령 전체를 실패로 만드는 것을 막는다 — 합/불 판정은 종료 코드가 아니라 출력 0건 여부다.
  </details>
- [ ] [D] `labs/` HTML 자산에서 유지 자리(`<title>`·주석·장식 기호·인용 출처·페이지 표기)를 걷어낸 뒤 잔존 줄표 0건
  <details>
  <summary>검증 명령 — repo 루트에서 실행, 출력 0건이면 통과</summary>

  ```bash
  for f in $(find labs -name '*.html' | sort); do
    n=$(grep -vE '<title>|^[[:space:]]*(<!--|/\*|-)|keypoint-label|quote-cite|page-no' "$f" \
        | grep -c '—')
    [ "$n" -gt 0 ] && echo "위반: $f ($n곳)"
  done; true
  ```

  - 설계 주의: 마크다운 필터를 쓸 수 없어 HTML용으로 따로 세웠다. 제외 패턴은 Task 0에서 실측한 유지 자리 형태를 그대로 특정한 것이고, 착수 시점 위반은 `classical.html` 2곳(804·828행)뿐이다.
  - 과소 검출 여지: 렌더링 본문과 주석이 한 행에 섞이면 그 행이 통째로 빠진다. 현재 대상 5개 파일에는 그런 행이 없고, 새로 생기면 이 접기에 예외 근거를 남긴다.
  </details>
- [ ] [D] `mkdocs build --strict` 종료 코드 0 (docs 변경 반영 후)
  <details>
  <summary>검증 명령 — 종료 코드 0이면 통과</summary>

  ```bash
  .venv/bin/mkdocs build --strict
  ```

  - 설계 주의: 로컬 PATH에 `mkdocs`가 없어 repo의 `.venv/bin/mkdocs`로 실행한다 (#49 검증 관례).
  </details>
- [ ] [D] Slidev 빌드 종료 코드 0 (slides.md 변경 후)
  <details>
  <summary>검증 명령 — 종료 코드 0이면 통과</summary>

  ```bash
  (cd slides && npm run build)
  ```

  </details>
- [ ] [QD] 전환 결과가 기준에 정합 — 쌍점 뒤가 길어져 앞 문맥이 희석된 곳이 없고, 하위 목록 분리가 적절하며, 유지 자리를 과잉 전환하지 않음  (검증: 교차모델 audit이 채점, 별도 세션)  ← 강등 사유: "부연이 길다"·"문맥 희석"은 의미 판단이라 명령으로 환원 불가
- [ ] [ND] 사용자가 대상 페이지를 직접 점검하고 피드백 반영까지 승인  (검증: 사람 리뷰)  ← 강등 사유: 교육 콘텐츠 문체 적합성은 최종적으로 저자(사용자) 판단

## 전제 (Assumptions)

- **사용자 합의(2026-08-10, 이 대화에서 확정)**: 정리 범위는 docs 잔여 + `labs/` 전체 + `slides/slides.md` 전부 포함. 검토 후 버린 대안: labs(약 262곳, docs의 약 1.8배)·slides(185곳)를 분량 근거로 별도 이슈 분리 — 사용자가 전부 포함으로 확정해 폐기.
- **issue-0049 종결(2026-08-10, 사용자 확정)**: Task 9·10 추가분의 교차모델 재감사는 수행하지 않고 종결, 디렉토리는 archive로 이관. 이관 커밋이 이 이슈의 작업 브랜치(`issue-0050`)에 포함된다.
- **정리 대상 문자**: 줄표는 U+2014(—)다. 하이픈(-)·엔 대시(–)는 대상이 아니다.
- **slides 후행 순서**: ADR-0002 구조상 slides는 docs의 파생이므로, docs 사용자 점검 종료 후에 `slides/slides.md`를 정리한다 (plan Task 순서의 근거).
- **표현 원칙(#49에서 확정, 전환 문장을 새로 쓸 때 적용)**: 구어체 회피(서버·프로그램은 "실행되다·위치하다"), 흔치 않은 공간 은유 회피, "잇다"→"연결", "닿다"→"접근". 전환은 문장부호만 바꾸는 것이 원칙이나, 문장을 분리·재구성할 때 이 원칙을 어기는 새 표현을 만들지 않는다.
- **검증 필터의 한계**: 완료의 정의 `[D]`의 유지 자리 필터는 구조 기반이라, 새 예외 형태가 나오면 구현 시점에 필터를 보정하고 접기 주석에 남긴다.

### Task 0에서 확정한 전제 (2026-08-10, 사용자 질의·답변)

- **#49 이월 후보 2건 포함**: `docs/basics.md`의 "도착점"(90행)·표 머리글 "축"(104행)을 이 이슈에서 함께 정리한다. 근거는 basics.md를 Task 2에서 어차피 수정하고, 두 건 모두 이미 확정된 표현 원칙(공간 은유 회피, 기준을 직접 서술)에 해당한다는 점이다. 검토 후 버린 대안: 원장 이관, "축"만 정리.
- **표 셀 안 줄표는 전부 전환**: 1열의 명칭 라벨("1단계 — 챗봇 사용")도 전환 대상이다. 슬라이드의 `—<br/>`는 `:<br/>`로 바꿔 줄바꿈 구조를 유지한다. 검토 후 버린 대안: 명칭 라벨만 유지 자리로 두기(부 명칭과 같은 계열로 보는 안), 표 셀 전면 유지.
- **SKILL.md 코드블록 안도 전부 전환**: 출력 형식 명세와 예시 출력 모두 전환하며, 쌍점이 이미 라벨 구분자로 쓰인 자리는 괄호·문장 분리로 처리해 쌍점 중복을 피한다. 형식 명세와 예시 출력은 같은 형태로 맞춘다. 검토 후 버린 대안: 코드블록 전면 유지, 플레이스홀더 안내문만 전환.
- **labs HTML 자산의 산문 포함**: `classical.html` 804·828행 2곳을 범위에 넣는다. 828행은 `wrong-answer-note/SKILL.md` 144행과 같은 항목이라, SKILL.md만 전환하면 실습자가 보는 완성 예시와 표기가 어긋난다. 검토 후 버린 대안: 828행만 정합 목적 예외 반영, HTML 전면 비포함 후 원장 등재.
- **security-guide 잔여분 경계는 실질 쟁점 아님**: 외부 연결 절(`{ #external-connection }`, 115행 이후) 안의 줄표는 전부 링크 라벨 안이라 이미 유지 자리다. 잔여 전환 대상은 무료 AI 도구 절 1곳(82행)뿐이다.
- **범례 행은 유지 자리**: `docs/security-guide.md` 193행·`slides/slides.md` 1760행의 범례는 표의 "해당 없음" 기호 자체를 설명하는 문장이라 줄표를 남긴다. 검증 필터가 이를 위반으로 세므로 예외를 추가했다.
- **labs 집계 보정**: 설계 시점 "22개 파일·약 262곳"은 실측 23개 파일·271곳이다. 누락됐던 `labs/step02-file-classifier/sample-files/README.md`는 줄표 0건이라 작업량 변화는 없다.
