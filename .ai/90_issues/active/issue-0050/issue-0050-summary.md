- **수행 내용 요약**: `docs/index.md` 36곳·`docs/intro.md` 25곳을 전환했다. 라벨 뒤 짧은 부연은 쌍점, 서술형 라벨(메타 원칙 ③의 "읽지 않은 결과물은…")은 문장 분리, 쌍점이 이미 쓰인 자리("예:" 등 3곳)는 괄호로 처리했다. 3단계 표 1열 명칭 라벨 3곳과 모델 비교 표 2곳(Fable·Sonnet)은 같은 열의 기존 괄호 표기에 맞춰 전환했다. intro의 링크 목록은 「공식 문서·참고 자료」 3개 하위 목록(시작하기·자산화/확장·운영/지원)과 「함께 읽어보세요」까지 목록 단위로 일괄 쌍점 전환했고, index의 「함께 읽어보세요」 3행도 같은 형식이라 함께 맞췄다. 검증 2건 통과: 두 파일 잔존 줄표 0건, `.venv/bin/mkdocs build --strict` 종료 코드 0.
