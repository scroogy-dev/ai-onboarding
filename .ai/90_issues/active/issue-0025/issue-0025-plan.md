### Task 2: 용어 안내 한 번 결합 — AI 챗봇 / AI 에이전트

- [x] 완료

- **작업 내용**:

- **완료 기준**: 페이지 진입 직후 용어 안내가 1회 노출되며, 이후 본문은 짧은 형태로 자연스럽게 읽힌다.
- **결정 근거**: 사용자 의도 — *"처음 언급될때 안내 한번이면 되지 않을까"*. 메모리 `feedback_terminology-prefix-once.md`로 정착.

  4. 비개발자 친화 톤으로 각 링크에 한 줄 설명을 붙인다 (역할·언제 보면 좋은지).
- **완료 기준**: 신설 섹션이 도입부에 추가되어 있고, 외부 링크가 모두 정상 응답하며, ko 페이지가 있는 경우 ko 경로를 사용한다.
