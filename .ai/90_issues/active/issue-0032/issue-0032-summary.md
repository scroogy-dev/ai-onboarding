### Task 5: 핵심 후보 3 — AI 결과물 검토·이해 의무

- **결과**: 완료
- **수행 내용 요약**:
  - `docs/index.md` `### AI 활용 메타 원칙` 섹션 ② 다음에 ③ "AI 결과물 검토·이해 의무" `!!! abstract` 박스 추가. 구성: 핵심 메시지(읽고 이해한 상태에서 사용) + 2 bullet(읽지 않은 결과물 미사용·이해 부족 시 AI에 설명 요청) + "프롬프트로만 진행"과의 짝 관계 설명 + step04 사례 한 줄 호출.
  - `labs/README.md` 진행 원칙 섹션을 단일 원칙(① 프롬프트로만 진행)에서 두 원칙 구조로 확장. ②로 "결과물은 반드시 읽고 이해합니다" 추가, GitHub 마크다운에서도 잘 렌더링되도록 `### ① / ### ②` 부제로 분리. 두 원칙이 짝임을 도입 한 줄로 명시.
  - `docs/labs.md`에 mirror admonition — 같은 헤더 구조(`## 진행 원칙` + 짝 안내) 위에 `!!! tip "① ..."` `!!! tip "② ..."` 두 박스로 동기화.
  - step04 호출은 docs/index.md ③ 박스 안에 자연어로 흡수("자녀 답안을 인식한 결과 엑셀을 다음 단계로 넘기기 전에 본인이 한 번 읽고 검토"). step04 본문 자체는 이슈 비포함 범위라 손대지 않음.
  - 사용자 보강 가이드(2026-05-09) 반영 — 박스 ③에 **검토 깊이 차등화** 단락 추가. "단, 모든 결과물을 같은 강도로 검토하라는 뜻은 아닙니다 → 깊이는 영향 범위에 비례 → 코드는 큰 흐름·실패 동작·민감 데이터까지 → 1회성/프로토타입은 가벼운 검토" 흐름. 단정 톤은 유지하되 비개발자가 "전부 이해 못 하면 못 쓴다"로 오독하지 않도록 현실 차등화 단서를 끼움.
  - 톤 일관 — `labs/README.md` ②와 `docs/labs.md` ②에도 같은 결의 차등화 단서를 4번째 bullet로 한 줄씩 추가하고 `#meta-principles` ③으로 링크. 본문 풀이는 도입 박스 ③에 맡기고 labs 쪽은 단서만 짧게 노출(중복 회피).
  - mkdocs `--strict` 빌드 정상(보강 후 0.65s).
- **특이 사항**:
  - "검수 자리" 같은 spec/notes의 압축 표현은 docs 본문에 옮기지 않고 "본인이 한 번 읽고 검토"로 자연어 전환(메모리 `feedback_internal-jargon-translation` 적용).
  - labs/README.md는 admonition이 없으므로 `### ① / ### ②` 부제 두 개로 시각 구분 — bullet 평탄화 회피(메모리 `feedback_preserve-intentional-emphasis` 적용).
  - docs/labs.md 박스의 admonition 종류는 기존 `!!! tip`을 유지(① 박스가 이미 tip이었음, ②도 같은 결).
  - Task 9의 메모리 후보 `feedback_labs-review-output.md`는 본 Task에서 정착한 시리즈 차원 원칙을 메모리화하는 것 — Task 9에서 신설/보류 결정. 차등화 가이드("검토 깊이는 영향 범위에 비례, 1회성·프로토타입은 가벼운 검토 충분")도 같이 메모리화 후보로 검토.
