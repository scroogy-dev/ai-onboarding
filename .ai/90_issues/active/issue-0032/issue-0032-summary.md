- **특이 사항**:

  - 페르소나 박스의 "전문성 부여" 보수 논거는 메타 원칙 ③(결과물 검토)와 자연스럽게 이어짐 — 잘못된 권위 부여로 환각이 강해지면 검토 부담만 늘어남. 박스 마지막 인용으로 ③에 다리 놓음.
  - "맥락 오염" 같은 노트의 압축 표현은 docs 본문에서 "AI가 앞에서 한 말을 잊거나 어긋나기 시작할 때"로 자연어 전환(메모리 `feedback_internal-jargon-translation` 적용).
  - 사용자 지적(2026-05-09)으로 박스 헤더 "④ 컨텍스트(대화방) 위생" → "④ 컨텍스트(대화방) 관리"로 정정. "위생(hygiene)"은 영어권 LLM 커뮤니티 표현(context hygiene)의 직역으로 한국어 비개발자에게 직관적이지 않음. spec/notes의 압축 표현이 docs 본문에 새 노출되는 자리에서 jargon 전환을 빠뜨린 케이스.
  - 사용자 보강 가이드(2026-05-09) 반영 — 박스 ④에 두 보강:
    - 새 bullet "**계획 단계가 끝나고 실행 단계로 넘어갈 때**"를 신호 목록에 추가. 메타 원칙 ①의 시간적 분리(계획/실행)를 컨텍스트 차원에서도 적용한다는 메시지로, ①과 ④의 짝 관계를 분명히 함.
    - **회의 메타포** 두 자리 활용 — (1) "대화가 너무 길어졌을 때" bullet에 "회의가 길어지면 사람도 집중도가 떨어지듯" 비유 끼움. (2) 옮길 때 정리 단락을 "회의록처럼 정리해 가져갑니다 — 회의를 두 번에 나눠 하면 다음 회의에 회의록을 들고 가야 맥락이 이어지듯" 메타포로 풂. 마지막 인용에서 이 "회의록" 자리가 메타 원칙 ①의 **계획 문서·실행요약**과 같은 역할이라는 호출로 시리즈 차원 일관 메시지 강화.

  - 사용자 보강 가이드(2026-05-09 — 보강 #2) 반영 — ④ 박스에 3곳 추가:
    1. **컨텍스트(맥락) 정의 단락**을 박스 첫 단락으로 신설. "AI가 한 번의 대화에서 함께 보고 있는 모든 입력의 묶음(주고받은 메시지·붙여넣은 문서·첨부 파일 전부) → AI는 매번 처음부터 다시 읽음 → 길어질수록 분량 커지고 한도 초과 시 앞쪽부터 흐려짐"을 비개발자 친화 자연어로 풀이. 그동안 박스가 **언제** 끊을지(신호)·**어떻게** 옮길지(회의록)만 다루고 **무엇이** 컨텍스트인지가 빠져 있던 점 보강.
