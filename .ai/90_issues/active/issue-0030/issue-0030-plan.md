### Task 1: 실습 위치·명명 규칙 의사결정

- [x] 완료
- **목표**: 실습 자료의 거주 위치와 디렉토리 명명 규칙을 사용자와 합의해 확정한다.
- **결정 사항**:
  - **위치**: repo 루트 `labs/` (사이트 미노출). 가이드 마크다운과 결과물 자산(SKILL.md·스크립트 등)을 한 디렉토리에 묶어 zip 다운로드 시 학습자가 가이드까지 함께 참고 가능하도록 함. ADR-0002의 "`docs/`는 콘텐츠 SSoT" 컨셉과도 정합(코드성 자산은 사이트 빌드에 섞이지 않음).
  - **명명 규칙**: `stage<단계번호>-<2자리 순서>-<하이픈 영문 설명>` 형식. 예: `stage2-01-meeting-summary`, `stage3-01-excel-classifier`. ADR-0001의 3단계 모델(2단계·3단계만 실습 대상)이 경로에 직접 노출되어 README·nav 별도 그룹핑 없이도 학습자가 단계 인지 가능. 모든 구분자는 하이픈 — 프로젝트 일관성·`docs/` 규칙 모두 충족.
  - **사이트 연결**: 루트 `labs/`는 사이트에 노출되지 않으므로 `docs/` 내 어딘가(index.md 또는 별도 안내 페이지)에서 GitHub labs 디렉토리·zip 다운로드 링크를 안내. 구체 위치는 Task 3에서 결정.
- **완료 기준**: 위치·명명 규칙 두 결정이 합의되어 본 plan에 명시되었다. ✅
