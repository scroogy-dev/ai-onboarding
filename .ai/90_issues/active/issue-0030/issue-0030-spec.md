# Issue #30 스펙 — 실습 자료 생성

> GitHub: https://github.com/scroogy-dev/2026-ai-edu/issues/30

## 목표 (Goal)

본 교육의 실습 자료(가이드 + 결과물 예시)가 거주할 **디렉토리 구조를 확정**하고, **실습 과제 후보 목록을 선정**하여 후속 이슈에서 개별 실습 콘텐츠를 작성할 수 있는 골격을 마련한다.

---

## 범위 (Scope)

**포함 (In)**

- 실습 자료의 **위치 결정** — repo 루트 `labs/` vs `docs/labs/` (사이트 노출 여부 포함)
- 실습 디렉토리 **명명 규칙 결정** — 순서 표현 방식(`01-xxx` 등 번호 접두사 사용 여부·형식)과 구분자(하이픈/언더스코어). `docs/labs/` 위치 시 프로젝트 규칙(영문 소문자·하이픈)이 디렉토리에도 강제 적용됨
- ADR-0001의 **AI 활용 3단계 모델**(1: 챗봇 / 2: 프롬프트 재활용·Agent Skills / 3: 에이전트·Cowork)에 매핑한 **실습 과제 후보 목록 선정**
- 첫 실습용 **디렉토리 템플릿 골격**(README/가이드 마크다운 + 결과물 예시 스킬 자리) 생성
- 위 결정에 따른 ADR 작성 (실습 자료 구조·명명 규칙 결정 기록)

**비포함 (Out)**

- 개별 실습의 본문 콘텐츠 작성 — 후속 이슈에서 실습 단위로 진행
- 사내용 실습 자료 — 회사 내부 repo로 분리(이미 결정됨)
- 실제 예시 스킬(SKILL.md, 스크립트) 구현 — 후속 이슈
- 슬라이드(`slides/`) 동기화 — 콘텐츠 작성 이후

---

## 완료의 정의 (Definition of Done)

- [ ] 실습 자료의 **위치**(루트 `labs/` vs `docs/labs/`)가 결정되어 ADR로 기록되었다
- [ ] 디렉토리 **명명 규칙**(순서 표현 + 영문 소문자·하이픈 정책)이 결정되어 ADR로 기록되었다
- [ ] AI 활용 3단계 모델에 매핑된 **실습 과제 후보 목록**이 작성되어 이 이슈 디렉토리(또는 ADR)에 남았다
- [ ] 결정된 위치에 **첫 실습용 골격 디렉토리**가 생성되었다 (README/가이드·결과물 예시 자리)
- [ ] 사이트 노출 여부에 따른 `mkdocs.yml` nav 또는 README 링크 처리가 반영되었다
- [ ] AI-CONTEXT.md의 프로젝트 규칙(`docs/` 하위 디렉토리는 영문 소문자·하이픈, `docs/` 페이지 파일에는 번호 접두사 회피)과의 정합이 ADR에서 명시적으로 다뤄졌다
