### Task 1: #9 선택지 비교 + 결정

- **결과**: 완료 — **(a) 유지** 결정
- **수행 내용 요약**:
  - 현재 상태 재확인: `docs/labs.md`(59줄, 인덱스만)·`labs/README.md`(67줄)·step별 README(25~78줄)·stage README(83~253줄). stage 본문 합산 ~1,328줄, 자산(`*-template.html`·`example-output.html`·`SKILL.md`·sample-files)이 상대 경로로 README에서 참조됨.
  - 선택지 (a)/(b)/(c) 비교 후 사용자와 함께 (a) 결정.
- **결정 근거**:
  1. ADR-0006이 명시한 "학습자 피드백 후 재검토" 조건이 아직 충족 안 됨 — 피드백 없이 (b)/(c)로 가면 추측 기반 변경.
  2. `labs/README` 및 `step*/README`는 GitHub 렌더링이 자연스러워, 사이트 진입자도 GitHub 한 번 점프로 본문 도달 가능.
  3. (b)의 두 벌 관리 부담이 즉시 효익보다 큼 — 시리즈가 안정화되기 전엔 본문이 자주 손댐.
  4. (c)는 ADR-0006 결정 1(zip 친화) 본질 뒤집기 — 트리거(학습 진행이 실제로 막힌다는 증거)가 없음.
- **특이 사항**: (a) 유지 결정 직후 "사이트·강의 진행 시 본문을 어떻게 보여줄지" 우려가 제기되어, Task 3은 '빈 작업'에서 **'진입 링크 보강'(docs/labs.md·slides/slides.md 표 step 셀에 GitHub README 직링크)** 으로 재정의. 본 이슈의 실제 작업 중심은 Task 3(가벼운 보강) + Task 4(#6 사용량 화면 안내).
