# #56 Task 4 ― 1부 뒷부분 동기화 완료 (화면 확인 승인·커밋)

<!-- 상태 스냅샷. 2026-09-09 사용자 승인으로 Task 4를 마감했다. -->

## 배경 (Why)

<details>
<summary>상세 펼치기</summary>

#56은 #55로 확정된 `docs/`를 기준으로 `slides/slides.md`를 전수 대조해 드리프트를 0건으로 만드는 이슈다.
Task 4는 1부 뒷부분(착수 시점 27~47장, What·How·메타 원칙) 구간을 맡는다.

Task 1에서 노트 매핑표를 HEAD 기준으로 다시 잡다가, **대응 docs 절 자체가 사라진 슬라이드 4장**이 새로 드러났다.
#55의 커밋 `dd24721`(과 `b70a819`)이 `docs/index.md`에서 「1·2단계 예시 카드」·「왜 단계가 이어지나요?」 tip·
「어떤 결과물을 만들 수 있나요?」 표·「대상별 실행 계획」 절을 삭제했기 때문이다.
사전 분석 노트에 없던 항목이라 처리 방향을 Task 4의 사용자 승인으로 넘겨 두었다.

</details>

## 논의 요약

<details>
<summary>상세 펼치기</summary>

spec DoD R4는 슬라이드 전용 콘텐츠의 처리 방향을 세 가지로 둔다: **docs 편입 · 삭제 · 발표용 완충 유지**.
대응 소멸 4장에 대해 네 갈래(4장 전부 삭제 / 35장만 삭제 / 4장 전부 발표용 완충 유지 / docs 편입)를 제시했고,
사용자가 **4장 전부 삭제**를 선택했다. ADR-0002의 단방향 파생을 우선한 판단이며,
트랙별 실습 예시는 새 번호 77·78장(실습 시리즈·step별 학습 포인트)이 맡는다.

30장 [4] 카드는 별도 문제였다. R1 게이트가 「100번」 0건을 요구하는데,
정정 방향이던 docs 문장(「한 번 만들고 여러 번 쓰는 것이 합리적」)도 #55에서 함께 삭제돼 바꿔 넣을 표현이 없었다.
세 갈래(「여러 번」으로 / 현재 docs 문장에 맞춤 / 카드 삭제) 중 **카드 삭제**로 확정했다.

37장은 예시만 바꾸면 카드 라벨(「구조화된 프롬프트」)과 내용(「먼저 계획만 짜주세요」)이 어긋난다.
#55가 docs 예시 축을 「프롬프트 구조화 여부」에서 「계획 문서 유무」로 옮겼기 때문이며,
**제목·라벨까지 docs 축으로 전면 교체**하기로 했다.

33장 하단 💡 한 줄은 대응 tip이 삭제됐지만 「단계가 올라가도 배운 개념이 이어진다」는 학습 동기 메시지라
**발표용 완충으로 유지**하고 표기만 「Agent Skills」에서 「Skill」로 바꿨다 (spec 전제 15의 덱 첫 등장 1회 규칙).

</details>
