# Issue #52 ― 1부 docs↔slides 동기화 점검표 (Task 5 산출물)

> 점검 기준: #50이 `docs/`에 반영한 변경 커밋 전부 (PR #53 병합 커밋 `0515ca3`의 두 부모 범위, 실측 12건).
> 판정: **반영**(슬라이드에 같은 내용이 있음) / **해당 없음**(슬라이드에 대응 서술 자체가 없음) / **누락**(대응 서술이 있는데 docs 변경이 반영되지 않음).
> 두 표면이 다르면 docs가 정답이다 (ADR-0002 결정 5). 1부 전수 대조는 하지 않는다 (spec 전제 9).
> 판정 참고: 이슈 #50 완료 댓글의 Task 4 점검 라운드 1~10 목록.

## 3. 누락 보정

#50 커밋 축의 **누락은 0건**이다. 다만 같은 기준을 현재 덱 전체에 재실행하는 과정에서 **이 이슈가 신설한 2부 슬라이드의 회귀 2건**을 발견해 함께 보정했다. 판정 근거로 쓴 상태(`0515ca3`에서 0곳)가 이 이슈 산출물에서 깨져 있었으므로, 그대로 두면 #50이 세운 기준이 무효가 된다.

### 보정 1 ― 산문 줄표 28곳 (spec 전제 1 위반)

#50 산문 줄표 게이트 실측: `0515ca3` **0곳** → `7b1a262`(Task 3 종료) **26곳** → Task 4 반영 후 **28곳**. 전부 이 이슈 Task 2·3·4가 신설한 자리다.

- **본문 7곳**: 카드 헤더 6곳을 1부 관례인 쌍점으로 맞췄다 (1부는 「챗봇: 물어보기」·「모델: 생각하는 머리」처럼 전부 쌍점이고 줄표가 0건이다). 보안 요약 장 하단 안내 1곳은 페이지 제목과 절 이름을 줄표로 이어 붙인 자리라 「`보안 및 개인정보 가이드`의 「외부 연결」 절」로 갈랐다.
- **발표자 노트 21곳**: 「판단 ― 이유」 형태를 문장 분리로, 괄호 안 부연 2곳을 쉼표로 바꿨다.

보정 후 게이트 **0곳**으로 `0515ca3` 상태를 회복했다.

### 보정 2 ― 「닿다」 은유 6곳 (docs 표기와 불일치)

docs는 접근 가능 여부를 전부 **「접근하다」**로 쓴다(`connect/mcp-servers.md` 51·58·68·96행, `connect/connectors.md` 91행). 2부 슬라이드가 이를 **「닿다」**로 바꿔 쓰고 있었다. docs 전체에서 「닿」은 0건이라 파생 과정에서 새로 들어온 표현이고, 두 표면이 다르면 docs가 정답이다 (ADR-0002 결정 5).

본문 4곳(1952·2203·2265·2310행)과 발표자 노트 2곳(2231·2317행)을 docs 표기로 되돌렸다. 1부 320행의 「와닿는」은 관용 표현이라 대상이 아니다.

## 4. 점검 범위 밖에서 확인된 1부 불일치 2건

「실습 시리즈」 슬라이드(2835행 표)와 `docs/labs.md`가 두 셀에서 갈렸다. 이슈 #52 Task 1 조사에서 발견해 이월된 항목이다. 둘 다 **#50 변경 이력 밖**이라 spec 전제 9(좁은 점검)의 대상이 아니어서 사용자에게 판단을 물었고, **step04만 보정**하기로 확정됐다.

| 자리 | 슬라이드 | docs | 갈린 시점 | 처리 |
|------|----------|------|-----------|------|
| step03 핵심 학습 포인트 | 사진 입력·출처 충실성·외부 도구 연결 | Skill 활용 다양화 | #30에서 두 표면이 각각 작성 | 보류 (사용자 확정) |
| step04 핵심 학습 포인트 | 다단계 파이프라인 · **검수 자리** · 데이터/뷰 분리 | 다단계 파이프라인 + **검수 단계** + 데이터·뷰 분리 | #49 `68470ae`가 docs의 공간 은유 「자리」를 전수 교체할 때 슬라이드가 빠짐 | **보정 완료** |

### step04 보정 내역

`slides/slides.md`의 「검수 자리」 2곳을 docs 표기인 「검수 단계」로 바꿨다. 둘 다 청중이 보는 본문이다.

- 2844행: 「실습 시리즈」 표의 step04 핵심 학습 포인트 셀
- 1333행: 메타 원칙 ③ 슬라이드 하단 안내의 step04 사례

보정 후 `slides/`에 「검수 자리」 0건이다. 표기 차이 3종(항목 구분자 `·` 대 `+`, `데이터/뷰` 대 `데이터·뷰`, step 링크 라벨 축약)은 그대로 두었다. 발표 폭에 맞춘 슬라이드 압축이고 같은 덱의 「step별 학습 포인트」 카드(2910행)도 `데이터/뷰`를 쓰고 있어, 이 셀만 바꾸면 덱 안에서 표기가 갈린다.

### 남는 사실 ― `labs/` 본문은 여전히 「검수 자리」

#49 `68470ae`의 전수 교체는 `docs/`만 대상이었다. `labs/` 본문에는 「검수 자리」가 24곳 남아 있고(`labs/README.md` 1곳 + `step04-wrong-answer-note/` 하위 23곳), 그중에는 `labs/README.md`의 같은 요약 표와 stage 2의 학습 메시지 제목(`### ★ 검수 자리 ★`)이 포함된다. 슬라이드는 ADR-0002상 `docs/`의 파생이므로 `docs/labs.md`를 따르는 것이 맞지만, **`labs/` 표면은 아직 옛 표현을 쓴다**. 이 이슈의 범위 밖이라 손대지 않았다.
