#### F-2: 커넥터 검토 분류 보정이 `Custom`과 구성안까지 닫지 못함

- **위험도**: 중간(MEDIUM)
- **영향 축**: 기능 저하
- **발생확률 축**: 통상 사용
- **카테고리**: 기능
- **관점**: 누락된 검증
- **계보**: F-2 잔여
- **권장 조치**:
  - SSoT인 docs에 `Custom`은 사용자가 직접 추가한 커넥터이며 Anthropic이 검토하지 않았다는 공식 분류를 반영한다.
  - 용어 사전과 슬라이드가 `Verified`·`Community`·`Custom`의 세 분류와 행동 기준을 같은 뜻으로 안내하게 한다.
  - 승인된 구성안 18장의 폐기 문구를 현재 분류로 갱신한다.
- **완료 기준**:
  - `docs/connect/mcp-servers.md`가 `Verified`는 품질·호환성 검토, `Community`는 선별 후 심층 검토 없음, `Custom`은 사용자 직접 추가·Anthropic 미검토로 구분한다.
  - 직접 추가한 커넥터에 검토 표시가 없다고 단정하는 문구가 docs·용어 사전·슬라이드·구성안에서 0건이다.
  - 구성안 18장의 핵심 메시지가 폐기된 「자동 검사만」·「표시가 없으면」 대신 현재 공식 분류를 쓴다.
  - Slidev 빌드와 MkDocs `--strict` 빌드가 통과한다.
