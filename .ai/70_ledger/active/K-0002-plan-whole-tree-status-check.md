# K-0002: plan 완료 기준의 범위 없는 작업 트리 검사가 보존 중인 감사 리포트로 실패함

- **유형**: known issue
- **등재일**: 2026-10-03
- **출처**: 이슈 #61 / audit 발견 F-1
- **위험도**: 낮음(LOW)
- **수용 사유**: 실패를 만드는 것은 `.ai/99_workspace/`의 미추적 감사 리포트뿐이고, docs·slides 범위(`git status --porcelain -- docs slides`)는 깨끗해 콘텐츠와 승인·화면 확인 기록에는 영향이 없다. 미추적 리포트는 `--clear`에서 archive 이관 또는 삭제로 정리되어 이슈 #61 안에서 해소되므로, 이미 완료된 Task의 기준 문구를 고치는 비용이 이득보다 크다.
- **재검토 조건**: 다음 이슈의 plan 완료 기준에 범위 없는 `git status --porcelain`(전체 작업 트리 검사)을 둘 때 함께 판단한다. 같은 불일치가 다른 이슈의 audit에서 다시 보고될 때도 재검토한다.
- **상태**: 수용

## 내용

이슈 #61 plan Task 6의 `[D]` 「작업 트리에 미커밋 변경이 없다」는 `git status --porcelain` 출력 0건을 요구한다.
계획 감사 리포트를 `.ai/99_workspace/`에 미추적으로 보존하는 것은 통상 진행 과정이라, 이 검사는 콘텐츠가 모두 커밋된 상태에서도 실패하고 summary는 차이를 특이 사항에 적은 채 완료로 기록했다.
검사가 확인하려던 대상(콘텐츠 커밋 여부)과 실제 검사 범위(전체 트리)가 어긋난 기술 품질 문제다.

## 재검토 이력

없음
