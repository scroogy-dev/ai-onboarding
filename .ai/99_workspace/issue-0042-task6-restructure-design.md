## 1. 설계 원칙 — "한 축에 한 집, 나머지는 링크"

각 대비를 **한 섹션이 대표(home)** 로 갖고, 다른 곳은 *다시 설명하지 않고 링크*한다. 각 spine 섹션 머리에 **"이 페이지가 보는 축"** 한 줄을 박아 역할을 드러낸다.

| 축 | 집(home) | 한 줄 정체 |
|----|----------|-----------|
| **사용 방식(정의)** 챗봇/에이전트 | intro §챗봇 vs 에이전트 (D5) | *무엇인가* — 물어보기 vs 맡기기 |
| **동기** 왜 만들어 재사용하나 | index What 도입(§3단계로 흡수) | *왜* — 반복엔 만들기가 합리적 |
| **학습 사다리** 1→2→3 | index §3단계 모델 (D2) | *어디까지* — 내 위치와 다음 칸 |
| **결과물 형태·비용** 1회성/스킬/앱 | basics §세 형태 (D6) | *얼마나 일관·비싼가* |
| **해부** 모델+하네스 | basics §모델+하네스 (D7) | *무엇으로 이뤄졌나* |
| **프롬프트 품질** 막연/구조화 | index How §실습 접근법 (D4) | *어떻게 쓰나* (별개 축) |

## 2. 목표 구조 (target TOC)

### 홈 `index.md` — *동기 + 작업 원칙* (정의는 도입에 위임)

```
Who   — 대상 · 사전지식 · 준비사항            [사용량 tip → 도입으로, 링크만]
Why   — 배워야 하는 이유 · 소프트웨어 가치
What  — 교육 목표
        · AI 활용 3단계와 내 위치              ← 동기(D1)를 이 도입부로 흡수, 카드 1세트만 유지
        · 어떤 결과물을 만들 수 있나요         ← 트랙별 결과물 표만, 폴더정리 카드(D3) 삭제
How   — 실습 접근법(계획→실행, D4) · 메타 원칙 ①~⑤ · 대상별 계획
```

### 도입 `intro.md` — *AI 지형 + 도구 + 핵심 개념 정의*

```
생성형 AI 소개 — 대표 제품 · 코딩 에이전트 · 챗봇 vs 에이전트(정의의 집, D5)
Claude 소개   — 기능 비교 · 모델 비교 · claude.ai/Cowork/Code · 사용량 확인(유일한 집)
공식 문서
```

### 기본 용어 `basics.md` — *용어·범위 해소* (현행 유지)

```
세 형태(D6) · 마크다운 · 에이전트=모델+하네스(D7) · 외부 컨텍스트
```

## 3. 이동표 (이동 / 병합 / 삭제 / 유지)

| 대상 | 처리 | 상세 |
|------|------|------|
| index §매번 시키기 vs 소프트웨어로 만들기 (D1) | **병합** | 핵심 논지([1][2][3][4] "반복엔 만들기")는 §3단계 모델 도입부로 흡수. **2카드 grid 삭제**(3단계 카드와 중복). quote "비개발자도 소프트웨어를 만든다"는 살림 |
| index §3단계 모델 (D2) | **유지(축 라벨 추가)** | mermaid·표·고객답장 2카드 유지 = spine의 대표 카드. 챗봇/에이전트 정의는 intro 링크로 대체(재정의 안 함) |
| index §어떤 결과물 (D3) | **카드만 삭제** | 트랙별 결과물 표는 유지(고유). 폴더정리 2카드 grid 삭제(묻기 vs 맡기기 중복) |
| index §준비사항 사용량 tip | **이동/링크** | 사용량 확인 how는 intro로 단일화, index는 한 줄 링크 (스크린샷 위치는 §5 결정) |
| intro §챗봇 vs 에이전트 (D5) | **유지(정의의 집)** | "이 대비가 정의의 집" 한 줄 + index 3단계로 내보내는 링크 |
| intro §사용량 확인 (C) | **유지(단일 집)** | index에서 들어오는 링크 받음 |
| basics §세 형태 (D6) | **유지(축 라벨)** | "결과물 형태·비용 축" 명시, 모델+하네스와 역할 분리 |
| basics §모델+하네스 (D7) | **유지** | 바이브 제거로 앞 끊김 → 도입부 한 줄 재손질(현 "intro 챗봇vs에이전트에서…" 유지면 OK) |
| index §실습 접근법 (D4) | **유지(별축)** | "프롬프트 품질 축"이라 spine과 다름을 톤으로 구분 |

**삭제되는 것**: before/after 카드 5세트 → **2세트**(index 3단계 + intro 챗봇vs에이전트)로. (D1·D3 카드 grid 제거)
