# Labs

> These are the hands-on lab materials for this training. **To make them easy to follow on your own computer**, the content lives in the `labs/` directory at the root of the GitHub repo, and this page only serves as an index.

---

## Ground rules

This series has two ground rules.

**① Work with prompts only.** This series recommends practicing doing every lab **with prompts only**.

- Don't edit files, code, or templates directly in an editor; ask AI with a prompt instead.
- Why: The goal of this series is to build the muscle of "driving software with words" through AI.
- When you get stuck, try asking for the fix with a prompt too. The urge to fix it by hand is exactly where the practice happens.

**② Always read and understand the output.** Even though you don't write it by hand, use and modify AI-made output only **after reading and understanding it yourself**.

- Don't use output you haven't read. This applies equally to [Markdown](basics.md#markdown), HTML, Excel, and Skill instructions.
- If you don't fully understand it, ask AI again, "Why did you build it this way? What does this part mean?", and go over it.
- Rule ① does not exempt you from review. Precisely because you don't write by hand, make a more conscious effort to understand it in depth.
- That said, **how deeply you review depends on the output's impact.** Go light on throwaway outputs and deep on outputs you will reuse or share. For detailed guidance, see [meta-principle ③](index.md#meta-principles).

## Series overview { #series }

Each step covers one topic, and within it you go through stages mapped to the [three-stage model of AI use](index.md#stage-model). **A step does not have to be a full course (stages 1, 2, and 3); each step includes only the stages its learning goals need.**

| step | Topic | Stages | Key learning points |
|------|------|-----------|----------------|
| **[step01-weather](https://github.com/scroogy-dev/ai-onboarding/tree/main/labs/step01-weather)** | Weather: free-form answer → structured → report | 1, 2, 3 | Unifying the text format, the leap to file outputs, separating data from view |
| **[step02-file-classifier](https://github.com/scroogy-dev/ai-onboarding/tree/main/labs/step02-file-classifier)** | File classification | 1, 2 | Designing Skill options (parameters) |
| **[step03-voca-quiz](https://github.com/scroogy-dev/ai-onboarding/tree/main/labs/step03-voca-quiz)** | English vocabulary quiz maker | 1, 2 | Image input, a constraint to stay faithful to the source, automatic links to an external dictionary |
| **[step04-wrong-answer-note](https://github.com/scroogy-dev/ai-onboarding/tree/main/labs/step04-wrong-answer-note)** | Wrong-answer notes from a child's graded test | 1, 2, 3 | Multi-step pipeline + review step + separating data from view |
