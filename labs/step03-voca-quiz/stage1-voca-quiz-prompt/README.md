# stage 1 ― 챗봇 자유응답 (단어장 사진 출제)

> 단어장 사진을 업로드하고 "랜덤으로 5개 출제해줘" 같이 자유응답으로 시켰을 때, **사진 속 뜻이 그대로 보존되는지·숙어 처리·출제 개수**가 어떻게 흔들리는지 직접 체감합니다.

---

## 학습 목표

- 같은 사진·같은 요청을 반복해도 챗봇이 **사진의 뜻을 마음대로 일반적 뜻으로 바꿔버리는** 흔들림을 관찰합니다.
- 출제 개수, 숙어 처리, 발음 도움 안내가 매번 들쭉날쭉하다는 사실을 직접 봅니다.
- stage 2에서 이 모든 흔들림을 **instructions의 강한 제약**으로 잡아내는 동기를 얻습니다.

---

## 사전 조건

- Claude 챗봇 사용 경험 (claude.ai 웹 또는 Claude Desktop 앱)
- **이미지 업로드가 가능한 환경**: claude.ai 웹·Claude Desktop 모두 지원합니다
- 단어장 사진 1장: 자녀의 영어 단어장 또는 임의의 단어 리스트가 적힌 페이지를 카메라로 촬영한 사진

> **단어장 사진이 없다면**: 영어 교재의 단어 정리 페이지, 단어 모음 PDF의 한 페이지를 캡처한 이미지 등 어떤 것이든 사용할 수 있습니다. 핵심은 **단어와 뜻이 함께 적힌 이미지**이고 **숙어가 한두 개 섞인 것**입니다(숙어 옵션 흔들림 관찰용).

---

## 절차

### 1. 같은 사진을 새 대화에서 3번 반복 출제 요청

Claude 챗봇을 열고, **새 대화**에서 단어장 사진을 업로드한 뒤 다음 prompt를 입력합니다.

```
이 사진에서 영어 단어 5개만 랜덤으로 골라서 시험 문제처럼 만들어줘.
```

답을 받은 뒤 **새 대화**(이전 대화 닫기)에서 동일 사진·동일 prompt를 한 번 더, 또 한 번 더 반복해 총 3회를 채웁니다.

> 반드시 매번 **새 대화**에서 시작하세요. 같은 대화 안에서 반복하면 이전 맥락이 영향을 줍니다.

### 2. 답을 한 번에 비교

3개 답을 위에서 아래로 늘어놓고 다음을 비교합니다.

| 비교 항목 | 1회차 | 2회차 | 3회차 |
|---------|-------|-------|-------|
| 출제 개수 (5개 요청 → 실제) | | | |
| 사진의 뜻이 그대로 나왔는지 (사진 텍스트와 글자 단위 비교) | | | |
| 사진에 있던 부가 표기(괄호·슬래시·기호)가 살아있는지 | | | |
| 숙어(2단어 이상) 포함 여부 | | | |
| 정답·뜻을 어디에 배치했는지 | | | |
| 발음 도움 안내가 있었는지 | | | |

특히 **사진의 뜻이 그대로 나왔는지**가 가장 큰 변동 항목입니다. 같은 단어인데 어떤 답엔 사진 그대로 `(시야에서) 사라지다 / (존재가) 없어지다`가 나오고, 다른 답엔 AI가 임의로 `사라지다`로 줄여서 출력합니다.

### 3. 옵션을 말로 시도해 보기

이번엔 표현을 약간 바꿔 봅니다.

```
이 사진에서 단어 5개만 랜덤으로 출제해줘. 숙어는 빼고.
```

```
이 사진에 있는 단어로 영어 시험 좀 만들어줘.
```

```
이 단어장에서 10개만 출제해줘.
```

답이 어떻게 달라지는지 보세요. 어떤 답은 "숙어 빼고"를 잘 지키고, 다른 답은 그냥 무시합니다. 어떤 답은 단어 10개를 출제하고, 어떤 답은 5개로 줄여 답합니다.

---

## 관찰 포인트

- **뜻 흔들림**: 사진의 단어 뜻을 그대로 가져오는 게 가장 자주 깨지는 규칙입니다. AI가 자기가 아는 일반적 뜻으로 변환해 출력합니다. 자녀가 외운 뜻과 달라 채점이 어긋납니다.
- **사진의 부가 표기 누락**: 괄호 안 부연 설명·슬래시(/)로 구분된 동의어가 매번 사라지거나 다르게 합쳐집니다.
- **숙어 처리 일관성**: "숙어 빼고"라고 말로 해도 절반은 무시됩니다.
- **출제 개수 흔들림**: 5개 요청에 4개나 7개로 답하기도 합니다.
- **발음 도움 누락**: 부모가 자녀에게 단어를 읽어주려 할 때 도움이 될 정보(발음 도구 안내·발음 기호 등)는 자유응답에선 거의 등장하지 않습니다.

> 자녀의 학습 도구로 매일·매주 반복해서 쓰려고 할 때, **사진과 다른 뜻**·**누락·중복**·**숙어 처리 불일치**·**발음 도움 부재**가 누적되면 부모가 매번 결과를 손으로 검수해야 합니다. 이게 본 step의 가장 큰 페인포인트입니다.

---

## 정리

- 자유응답 챗봇은 **사진을 읽기**까지는 잘 하지만, **사진의 정보를 그대로 보존**하는 데는 약합니다. AI는 본인이 아는 일반 뜻으로 자연스럽게 끌려갑니다.
- 다음 stage 2에서는 **사진 + 숙어 옵션 + 출제 개수**를 함께 받고, **"사진의 뜻을 절대 수정하지 않는다"**·**"단어마다 발음 사전 직접 링크를 붙인다"** 규칙을 강제하는 Skill을 만들어 봅니다.
