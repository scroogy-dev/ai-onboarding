# step03-voca-quiz — 영어 단어 출제기

> 단어 리스트·난이도·문제 유형을 입력 받아 정형 출제하는 Skill. stage 1·2까지 다룹니다.

> **상태**: 본 페이지는 골격입니다. 상세 가이드 본문은 후속 이슈에서 작성됩니다.

---

## 학습 목표

자유 응답으로 매번 형식·난이도가 흔들리는 출제 → 입력값을 받아 정해진 형식으로 출력하는 Skill로 정형화하는 흐름을 익힙니다.

---

## stage 구성

| stage | 디렉토리 | 단계 | 학습 포인트 |
|-------|---------|------|------------|
| 1 | [stage1-voca-quiz-prompt/](./stage1-voca-quiz-prompt/) | 챗봇 자유응답 reference | "영단어 문제 내줘" 자유응답 — 매번 다른 형식·난이도 체감 |
| 2 | [stage2-voca-quiz-skill/](./stage2-voca-quiz-skill/) | 정형 출제 Skill | 단어 리스트·난이도·문제 유형(객관식·빈칸·뜻 맞추기) 입력 → 정해진 형식으로 문제 출력 |

---

## 선정 근거

ADR-0001이 후속 이슈로 명시한 **"Gems 기반 자동 출제기를 Claude Skill로 재설계"** 항목입니다. 출제 결과가 텍스트로 바로 사용 가능하므로 stage 3(파일 산출) 없이 stage 2까지로 충분합니다.
