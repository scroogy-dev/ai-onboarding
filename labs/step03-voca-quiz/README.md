# step03-voca-quiz ― 단어장 사진 기반 영단어 출제기

> 자녀의 영어 단어 숙제를 도울 때, **단어장 사진**을 찍어 올리면 그 단어와 뜻을 사진 그대로 보존해 **랜덤으로 N개**만 출제하고, **각 단어마다 네이버 영어사전 직접 링크**까지 붙여 발음을 손쉽게 들을 수 있게 하는 Skill을 만듭니다. stage 1·2까지 다룹니다.

---

## 학습 목표

- **멀티모달 입력**(이미지)을 받아 처리하는 Skill을 경험합니다.
- 자유응답이 가장 자주 어기는 **출처 충실성**(사진의 뜻을 그대로 복사) 제약을 instructions로 강제하는 패턴을 배웁니다.
- 단어 출력 줄마다 **외부 도구로 즉시 연결되는 직접 링크**(네이버 영어사전)를 자동으로 붙이는 형태로 Skill 출력 가치를 한 단계 끌어올립니다.

---

## 실제 활용 시나리오

부모가 자녀의 영어 단어 숙제를 도울 때 자주 겪는 어려움을 출발점으로 합니다.

| 기존 방식의 어려움 | Skill로 해결 |
|------------------|-------------|
| 단어장에서 부모가 직접 랜덤으로 골라야 함: 순서 까먹음·중복 출제 | 사진 한 장 + 개수 입력으로 랜덤 출제 |
| 부모의 영어 발음에 자녀·부모 모두 스트레스 | 단어마다 네이버 사전 직접 링크로 발음 즉시 청취 |
| 채점할 때 정답이 어디 있는지 매번 찾아야 함 | 단어와 뜻을 같은 줄로 정렬, 사진 그대로 보존 |
| 숙어가 섞이면 자녀 학습 흐름과 안 맞음 | 옵션 한 단어로 숙어 포함/제외 |

## stage 구성

|-------|---------|------|------------|
| 1 | [stage1-voca-quiz-prompt/](./stage1-voca-quiz-prompt/) | 챗봇 자유응답 reference | 사진 업로드 + 자유응답 출제: 뜻이 사진과 달라지고(AI가 임의로 일반적 뜻으로 변환), 숙어·개수가 매번 흔들림 |

## 선정 근거

ADR-0001이 별도 이슈로 미뤘던 **"Gems 기반 자동 출제기를 Claude Skill로 재설계"** 항목을 본 step에서 다룹니다. 출제 결과가 텍스트로 바로 사용 가능하므로 stage 3(파일 산출) 없이 stage 2까지로 충분합니다.

원본 시나리오는 Google Gems로 운영되던 부모용 영어 단어 출제 보조 도구였으며, 본 step에서는 그 기능을 **Claude Skill**로 옮기면서 단어별 발음 링크 출력까지 한 단계 진화시킵니다.
