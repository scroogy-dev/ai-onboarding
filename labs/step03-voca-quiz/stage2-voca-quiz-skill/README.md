# stage 2 ― 정형 출제 Skill (단어장 사진 출제)

> [stage 1](../stage1-voca-quiz-prompt/)에서 자유응답으로 흔들리던 출제를, **사진 입력 + 숙어 옵션 + 출제 개수**를 받는 Skill로 정형화합니다. 사진의 뜻을 절대 수정하지 않게 강제하고, 단어마다 **네이버 영어사전 직접 링크**를 자동으로 붙입니다.

---

## 학습 목표

- **이미지(멀티모달)** 를 입력으로 받는 Skill을 직접 만들어 봅니다.
- 자유응답이 가장 자주 어기는 **출처 충실성**(사진의 뜻을 그대로 복사) 제약을 instructions로 강제하는 패턴을 익힙니다.
- 출력에 **외부 도구로 즉시 연결되는 직접 링크**(네이버 영어사전)를 자동으로 붙여, 학습 도구로서의 가치를 한 단계 끌어올립니다.

---

## 사전 조건

- [stage 1](../stage1-voca-quiz-prompt/) 수료 (자유응답 출제의 흔들림 ― 특히 뜻 변경 ― 을 직접 본 상태)
- [step02 stage 2](../../step02-file-classifier/stage2-file-classifier-skill/) 수료 (옵션 받는 Skill을 만들어 본 상태) ― 권장
- Claude Pro 이상 요금제, **Claude Desktop**에 Skill을 설치할 수 있는 환경
- **이미지 업로드가 가능한 환경** ― Claude Desktop·claude.ai 웹 모두 지원
- 단어장 사진 1장 (stage 1과 같은 사진 사용 권장 ― 비교가 쉬워집니다)

---

## step02와의 차이 ― 텍스트 옵션 vs 이미지 + 출처 충실성

| 항목 | step02 (file-classifier) | step03 (voca-quiz) |
|------|------------------------|--------------------|
| 입력 모달 | 텍스트(파일명 리스트) | **이미지** + 텍스트 옵션 |
| 입력값 | 옵션 1개 | 사진 + 옵션(숙어) + 개수 |
| 핵심 제약 | 옵션별 확장자 매칭 | **사진의 뜻을 절대 수정하지 않음**(AI 환각 차단) |
| 출력 가치 | 분류 결과 보고 | 사진 보존 + 단어별 외부 도구 직접 링크 |
| Skill 자산화 강도 | 옵션 1축 | 멀티모달 + 출처 충실성 + 외부 연계 |

step02가 "옵션이 바뀌면 처리 대상이 갈리는" 패턴이었다면, step03은 "이미지에서 추출한 정보를 **수정 없이 그대로 보존하면서** 외부 도구까지 연결하는" 패턴으로 한 단계 더 풍부한 Skill 설계를 보여줍니다.

---

## 절차

### 1. 새 Skill 생성

Claude(웹 또는 Desktop)의 Skills 메뉴에서 **새 Skill 만들기**를 선택합니다.

| 항목 | 예시 입력값 |
|------|-----------|
| 이름 | `영단어 출제기` |
| 설명 | `단어장 사진을 받아 사진의 뜻을 그대로 보존한 채 랜덤으로 N개를 출제하고 단어마다 네이버 영어사전 직접 링크를 붙인다` |

### 2. Instructions에 출제 규칙 넣기

다음 내용을 Instructions에 붙여넣습니다.

```
역할: 영어 단어 시험을 도와주는 보조 교사. 사용자가 단어장 사진을 업로드하면 사진의 단어와 뜻을 정확히 추출해, 옵션과 개수에 맞춰 랜덤으로 출제한다.

[발음 링크 안내 ― 항상 최상단에 출력]

단어 목록을 출력할 때마다, 가장 위에 다음 안내 문구를 먼저 표시한다.

🔊 단어 발음을 들으려면 아래 안내 또는 각 단어 옆 링크를 사용하세요.
👉 네이버 영어사전: https://en.dict.naver.com/#/search
👉 네이버 사전 앱: App Store 또는 Google Play에서 "네이버 사전" 검색

[0단계 ― 옵션 확인]

사용자에게 다음을 확인한다.
- "숙어를 포함할까요, 제외할까요?"

사용자가 "숙어 제외"라고 하면, 2개 이상의 단어로 이루어진 숙어(예: put off, look forward to, take place 등)는 모두 제외한다.
별도 언급이 없으면 숙어를 포함한다.

[1단계 ― 단어 추출]

사진에서 영어 단어와 뜻을 정확하게 읽어낸다.

중요 규칙 (절대 어기지 않는다):
- 단어와 뜻은 사진에 적혀있는 내용을 **그대로** 사용한다.
- 뜻을 요약·수정·일반화·추가하지 않는다.
- 철자, 괄호, 기호, 슬래시(/) 등은 사진에 있는 그대로 유지한다.
- AI가 자체적으로 일반적인 뜻으로 바꾸는 것을 금지한다.
- "숙어 제외" 옵션이 활성화된 경우, 2개 이상의 단어로 구성된 표현(띄어쓰기 포함)은 추출 단계부터 제외한다.

[2단계 ― 랜덤 출제]

사용자가 단어 개수를 요청하면 추출한 전체 단어 중에서 랜덤으로 선택한다.

규칙:
- 같은 단어는 중복되면 안 된다.
- 요청한 개수만큼만 선택한다.
- 문제(객관식·빈칸 등)를 만들지 않는다. 단어와 뜻을 그대로 출력한다.

[출력 형식]

다음 형식을 정확히 사용한다 (다른 표현 금지).

🔊 단어 발음을 들으려면 아래 안내 또는 각 단어 옆 링크를 사용하세요.
👉 네이버 영어사전: https://en.dict.naver.com/#/search
👉 네이버 사전 앱: App Store 또는 Google Play에서 "네이버 사전" 검색

📚 출제 정보 | 숙어: <포함/제외> | 출제 수: <개수>

1. <영어단어> - <사진에 적힌 뜻 그대로> [🔊 발음 듣기](https://en.dict.naver.com/#/search?query=<영어단어>)
2. <영어단어> - <사진에 적힌 뜻 그대로> [🔊 발음 듣기](https://en.dict.naver.com/#/search?query=<영어단어>)
...

발음 링크의 query 값에는 해당 영어단어를 그대로 넣는다(공백·특수문자가 있으면 URL 인코딩한다).
숙어를 포함하는 경우라도 출제는 단어 단위로만 진행하므로 링크의 query는 단일 단어이다.

[추가 규칙]

- 인사말·격려 멘트·해설·추가 문장은 출력하지 않는다.
- 사진을 첨부하지 않은 메시지에는 한 줄로 답한다 ― "단어장 사진을 첨부해 주세요."
- 출제 개수가 누락되면 한 줄로 다시 묻는다 ― "몇 개를 출제할까요?"
```

> 이 instructions의 핵심은 **"중요 규칙" 블록의 출처 충실성 강제**와 **출력 형식의 단어별 링크**입니다. 자유응답에서 가장 자주 깨지는 두 부분을 명시적으로 잠급니다.

### 3. Skill 저장 후 호출

stage 1에서 사용한 단어장 사진을 그대로 첨부해 호출해 봅니다.

**호출 A ― 숙어 제외, 5개**

```
[사진 첨부]
숙어 제외하고 5개 출제해줘.
```

**호출 B ― 같은 사진, 숙어 포함, 5개**

```
[사진 첨부]
숙어 포함해서 5개 출제해줘.
```

**호출 C ― 같은 사진, 숙어 제외, 10개**

```
[사진 첨부]
숙어 빼고 10개 출제해줘.
```

**호출 D ― 사진 누락 케이스**

```
영단어 출제해줘.
```

(instructions의 "사진을 첨부하지 않은 메시지에는 한 줄로 답한다" 규칙이 동작하는지 확인)

**호출 E ― 개수 누락 케이스**

```
[사진 첨부]
숙어 포함해서 출제해줘.
```

(instructions의 "출제 개수가 누락되면 한 줄로 다시 묻는다" 규칙이 동작하는지 확인)

### 4. 결과 비교 ― 핵심 흔들림이 잠겼는지

호출 A·B·C 결과를 늘어놓고 다음을 확인합니다.

| 비교 항목 | 호출 A (제외, 5) | 호출 B (포함, 5) | 호출 C (제외, 10) |
|---------|---------------|---------------|------------------|
| 상단 발음 안내 | 항상 동일 | 항상 동일 | 항상 동일 |
| 출제 정보 헤더 | 숙어: 제외 \| 출제 수: 5 | 숙어: 포함 \| 출제 수: 5 | 숙어: 제외 \| 출제 수: 10 |
| 출제 개수 일치 | 5개 | 5개 | 10개 |
| 사진의 뜻 보존 (사진과 글자 단위 비교) | 일치 | 일치 | 일치 |
| 숙어 포함 여부 | 없음 | 있음(있던 경우) | 없음 |
| 단어별 발음 링크 | 모두 부착 | 모두 부착 | 모두 부착 |

### 5. stage 1 자유응답과 비교

[stage 1](../stage1-voca-quiz-prompt/)에서 받은 자유응답 3개와 본 stage Skill 호출 결과를 늘어놓고 비교합니다.

| 비교 항목 | stage 1 (자유응답) | stage 2 (Skill) |
|---------|------------------|----------------|
| 사진의 뜻 보존 | 자주 변경됨 (AI가 일반 뜻으로 바꿈) | 사진 그대로 |
| 부가 표기(괄호·슬래시) | 자주 누락 | 그대로 유지 |
| 숙어 옵션 일관성 | 절반 정도 무시 | 옵션대로 동작 |
| 출제 개수 일치 | 매번 흔들림 | 정확히 일치 |
| 발음 도움 | 거의 없음 | 단어마다 직접 링크 부착 |
| 같은 일 반복 | 매번 prompt 다시 작성 | 사진 + 한 줄 옵션 |

이 차이가 **"즉석 지시 → 출처 충실성을 강제하는 Skill로 정형화"의 효익**입니다. 자녀의 영어 단어 숙제 보조 도구로 매일·매주 그대로 재사용할 수 있는 형태가 됩니다.

## 관찰 포인트

- **사진의 뜻을 절대 수정하지 않음** 규칙이 가장 큰 가치입니다 ― 자녀가 외운 뜻과 채점 기준이 어긋나지 않습니다.
- 단어별 발음 링크는 **부모의 발음 스트레스**를 그대로 해소하는 출력 가치 ― Skill 출력에서 외부 도구 직접 연결을 자동화한 좋은 사례입니다.
- 입력값이 셋(사진·숙어·개수)이지만 모두 **사용자가 한두 단어로 말하면 끝**입니다 ― Skill 입력 설계가 잘 되면 호출은 짧아집니다.

---

## 트러블슈팅

| 증상 | 점검 |
|------|------|
| 사진의 뜻이 사진과 다르다 (AI가 임의 변경) | Instructions의 "중요 규칙" 블록 ― 특히 "AI가 자체적으로 일반적인 뜻으로 바꾸는 것을 금지한다" ― 가 그대로 들어있는지 확인. 같은 사진으로 다시 호출해도 반복되면 instructions 상단에 같은 규칙을 한 번 더 명시 |
| 숙어가 옵션과 다르게 처리된다 | Instructions의 "[0단계 ― 옵션 확인]"·"[1단계 ― 단어 추출]"의 숙어 제외 규칙이 살아있는지 확인 |
| 발음 링크가 안 붙거나 query가 비어있다 | Instructions의 "발음 링크의 query 값에는 해당 영어단어를 그대로 넣는다" 규칙이 있는지 확인. URL 인코딩이 필요한 단어(공백·특수문자)에서 깨지면 사용자가 링크를 클릭한 뒤 검색창에서 직접 다시 입력해도 됨 |
| 사진을 첨부했는데 "사진을 첨부해 주세요" 답이 온다 | 첨부가 실제로 업로드 완료되었는지 확인 (큰 파일은 업로드 시간 필요). 다른 형식이라면 PNG·JPG로 변환 후 재시도 |
| 사진 텍스트 인식이 일부 틀린다 | 모델의 OCR 한계입니다. 사진을 더 밝고 선명하게 다시 촬영하거나, 인식 결과 표를 사용자가 빠르게 검수한 뒤 출제 단계로 진행하도록 절차를 분리해 호출 |

## 막혔다면 ― 동작 가능한 참고 Skill

본 stage의 동작하는 Skill은 [`voca-quiz/SKILL.md`](./voca-quiz/SKILL.md)에 그대로 들어 있습니다.

- 따라하다 막혔거나 출력 형식이 흔들릴 때, 위 파일의 instructions를 그대로 복사해 본인 Skill의 instructions에 붙여 넣어 비교해 볼 수 있습니다.
- Claude Desktop의 Skills에서 디렉토리를 그대로 등록해 직접 호출해 볼 수도 있습니다.

## Project로도 운영하기 (Google Gems와 비슷한 사용 패턴)

본 Skill의 instructions는 **Claude Project**의 custom instructions 영역에 그대로 붙여 넣어도 동일하게 동작합니다. 자녀 옆에서 모바일 앱으로 사진을 찍어 즉석 출제하는 흐름이라면 Project 쪽이 더 자연스럽습니다.

| 측면 | Skill | Project |
|------|-------|---------|
| 작동 방식 | 어디서나 호출되는 도구 | 들어가면 자동 적용되는 전용 공간 |
| 진입 동선 | 일반 대화 → Skill 선택·호출 | 프로젝트 클릭 → 곧장 사진 + 한 줄 |
| Google Gems와의 유사성 | 도구 호출 모델 | **사실상 1:1 대응** |

운영 방법 (Project 사용 시):

1. Claude 앱(웹·데스크탑·모바일)에서 `영단어 출제기` 프로젝트 생성
2. **Custom instructions** 영역에 위 [`voca-quiz/SKILL.md`](./voca-quiz/SKILL.md)의 instructions 본문을 그대로 붙여넣기 (frontmatter는 제외)
3. (선택) 자주 쓰는 단어장 PDF·이미지를 Project Knowledge에 미리 올려두면 사진 첨부 없이도 호출 가능
4. 자녀 옆에서 앱 → 프로젝트 진입 → 사진 촬영·업로드 → "5개 출제, 숙어 빼고" → 결과

> instructions 본문은 Skill·Project 어디에 두든 동일하게 동작합니다. 차이는 **호출 동선**(어디서든 vs 그 공간 들어가면)뿐입니다 ― 사용 패턴에 따라 골라 쓰면 됩니다.
