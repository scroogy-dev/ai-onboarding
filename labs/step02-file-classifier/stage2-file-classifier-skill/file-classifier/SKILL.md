# 파일 분류기 Skill

옵션에 따라 동작이 달라지는 분류 Skill이다. 옵션을 인식하고 그 옵션에 맞는 확장자의 파일만 추려 보고하며, 파일시스템 접근 권한이 있을 때는 추가로 파일을 이동시킨다.

## 지원 옵션

| 옵션 | 매칭 확장자 |
|------|-----------|
| `excel` | .xls, .xlsx, .xlsm, .csv |
| `image` | .jpg, .jpeg, .png, .gif, .webp, .heic |

확장자 비교는 대소문자를 구분하지 않는다.

## 처리 절차

1. 사용자 메시지에서 **옵션**과 **대상 파일 목록(또는 첨부 파일·디렉토리 경로)** 을 식별한다.
2. 옵션이 누락되면 한 줄로 다시 묻는다 ― `어떤 종류로 분류할까요? (excel / image)`.
3. 지원하지 않는 옵션이면 한 줄로 답한다 ― `지원하는 옵션은 excel, image 입니다.`.
4. 옵션의 확장자 목록과 대상 파일을 비교해 매칭/미매칭 묶음으로 분류한다.
5. 파일시스템에 접근할 수 있는 환경이면 `<옵션>-files/` 디렉토리를 만들고 매칭 파일을 그 안으로 이동한다.
6. 아래 "출력 형식"으로 결과를 보고한다.

## 출력 형식

다음 형식을 정확히 사용해 출력한다. 인사말·부연 설명·항목 추가/삭제/순서 변경은 모두 금지한다.

```
📁 **옵션**: <excel | image>
🎯 **매칭 확장자**: <쉼표로 구분된 확장자 리스트>
✅ **매칭된 파일** (<개수>개):
- <파일명1>
- <파일명2>
⏭ **매칭되지 않은 파일** (<개수>개):
- <파일명1>
📦 **이동 결과**: <"이동 완료 → <옵션>-files/" | "분류만 수행 (파일시스템 미접근)">
```

각 묶음에 파일이 없으면 `(없음)`으로 표시한다.

## 호출 예시

사용자:
```
excel
report-2025.xlsx
photo.png
sales.csv
diagram.png
budget.xlsm
notes.txt
```

기대 출력 (Claude Desktop 일반 대화):
```
📁 **옵션**: excel
🎯 **매칭 확장자**: .xls, .xlsx, .xlsm, .csv
✅ **매칭된 파일** (3개):
- report-2025.xlsx
- sales.csv
- budget.xlsm
⏭ **매칭되지 않은 파일** (3개):
- photo.png
- diagram.png
- notes.txt
📦 **이동 결과**: 분류만 수행 (파일시스템 미접근)
```

같은 입력을 Cowork(파일 업로드) 또는 Code(디렉토리 경로) 환경에서 호출하면 마지막 줄이 `📦 **이동 결과**: 이동 완료 → excel-files/`로 바뀌고, 매칭 파일이 실제로 이동된다.
