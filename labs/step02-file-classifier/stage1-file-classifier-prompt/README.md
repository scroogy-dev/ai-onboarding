# stage 1 — 직접 prompt로 파일 이동 (Skill 없이)

> 같은 작업을 먼저 **Skill 없이 즉석 prompt로** 시도합니다. stage 2에서 만들 분류 Skill의 **출발점·비교 기준**이 되는 단계입니다.

---

## 학습 목표

- Skill 없이도 **Cowork·Code 같은 실행 매체**에서는 AI에게 직접 지시해 파일 이동을 시킬 수 있다는 점을 체감합니다.
- 같은 일을 매번 **즉석 지시**로 할 때의 한계(반복성·재사용성·결과 흔들림)를 직접 봅니다.
- stage 2에서 같은 작업을 Skill로 정형화할 때 **무엇이 좋아지는지** 체감할 수 있는 비교 기준을 만듭니다.

---

## 사전 조건

- Claude Pro 이상 요금제
- **Claude Cowork** 또는 **Claude Code** 환경 (파일시스템 접근이 필요)
- 분류해 볼 샘플 파일 — `step02-file-classifier/sample-files/`에 준비된 더미 8개를 그대로 사용하시면 됩니다 (엑셀 3 + 이미지 3 + 매칭 없음 2)

> ⚠️ Claude Desktop **일반 대화**는 파일시스템 접근이 없어 본 stage를 그대로 따라할 수 없습니다.
> step01-weather와 달리 본 step은 stage 1 단계부터 실행 매체(Cowork·Code)가 필요합니다 — 라벨은 학습 초점(즉석 지시 = stage 1)이지, 실행 환경 기준이 아닙니다.

---

## 절차

### 1. 샘플 파일 준비

repo의 [`labs/step02-file-classifier/sample-files/`](../sample-files/)에 분류 실습용 더미 파일 8개가 준비되어 있습니다.

| 매칭 옵션 | 파일 |
|---------|-----|
| `excel` | report-2025.xlsx, budget.xlsm, sales.csv |
| `image` | photo.png, diagram.png, icon.gif |
| (없음) | notes.txt, README.md |

- **Cowork**: 새 대화에 위 8개 파일을 업로드합니다 (디렉토리 선택 또는 드래그).
- **Code**: 해당 디렉토리에서 직접 작업하거나, 작업 위치로 복사합니다.

> 샘플을 직접 만들고 싶다면 `labs/step02-file-classifier/scripts/generate-samples.py`를 실행해 재생성할 수 있습니다 (Python 외부 의존성 없음).

### 2. 즉석 prompt로 분류·이동 지시

다음과 같이 한 줄 prompt로 지시합니다.

```
업로드한 파일들 중에 엑셀 파일만 골라서 excel-files/ 디렉토리로 옮겨줘
```

(Code 환경이라면 디렉토리 경로를 함께 알려줍니다 — `~/Downloads/test-files/ 안의 엑셀 파일만 골라서 ...`)

### 3. 결과 확인

AI가 보고하는 내용을 봅니다.

- 어떤 확장자를 "엑셀"로 인식했는지 (`.xlsx`만? `.xlsm`도? `.csv`는?)
- 어떤 파일을 옮겼는지 / 안 옮겼는지
- 만든 디렉토리 이름이 `excel-files/`인지, 다른 이름인지

### 4. 옵션을 바꿔 다시 지시

```
이번에는 이미지 파일만 골라서 image-files/ 디렉토리로 옮겨줘
```

### 5. 새 대화에서 똑같이 반복 — 흔들림 관찰

새 대화를 열고 같은 샘플로 같은 prompt를 다시 던져 봅니다. 다음 항목을 비교합니다.

| 비교 항목 | 첫 시도 | 두 번째 시도 |
|---------|--------|------------|
| 엑셀로 분류된 확장자 | (.xlsx, .csv?) | ? |
| 디렉토리 이름 | `excel-files/`? | `엑셀_파일/`? `excel/`? |
| 보고 형식 | 표? 줄글? 리스트? | ? |
| 빠뜨린 파일 | 있음/없음 | ? |

---

## 관찰 포인트

- **즉석 지시도 동작은 합니다** — Cowork·Code의 강점은 "자연어로 파일시스템 작업을 시킬 수 있다"는 것입니다.
- 다만 같은 일을 **반복**할 때 매번 prompt를 다시 적어야 하고, **확장자 누락·디렉토리 이름·보고 형식**이 흔들립니다.
- "엑셀이 뭐야?"의 정의(`.xlsm`을 포함할지 등)가 매번 흔들리는 게 가장 불편한 부분입니다.
- 이 흔들림을 잠그기 위해 다음 stage에서 **옵션 받는 Skill**로 정형화합니다 — 확장자 목록을 instructions에 못 박아 두면 같은 입력에 같은 결과가 나옵니다.

## 트러블슈팅

| 증상 | 점검 |
|------|------|
| "파일시스템에 접근할 수 없습니다" 응답 | Claude Desktop 일반 대화에서 시도하지 않았는지 확인 — 본 stage는 Cowork·Code 필요 |
| 업로드한 파일을 찾지 못한다 (Cowork) | 첨부 파일이 실제로 업로드 완료되었는지, 새 대화/같은 대화 안에 있는지 확인 |
| 디렉토리 경로가 안 통한다 (Code) | 절대 경로 또는 현재 작업 디렉토리 기준 상대 경로를 명시했는지 확인 |
