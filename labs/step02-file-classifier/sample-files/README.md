|------|---------|------|

| `budget.xlsm` | excel | 매크로 활성 OOXML |
| `sales.csv` | excel | UTF-8 텍스트 |
| `photo.png` | image | 16x16 RGB PNG |
| `diagram.png` | image | 16x16 RGB PNG |
| `icon.gif` | image | 1x1 GIF89a |
| `notes.txt` | (없음) | 일반 텍스트 |
