# stage 1 ― 챗봇 자유응답 (날씨)

> 자유응답으로 "오늘 날씨 어때?"를 던졌을 때 매번 답의 형식이 어떻게 흔들리는지 직접 체감합니다.

---

## 학습 목표

- 같은 질문을 반복해도 챗봇 답의 **형식이 매번 달라진다**는 사실을 직접 관찰합니다.
- 그 차이가 일·학습에 쓰일 때 어떤 비용으로 돌아오는지 감을 잡고, **stage 2(Skill)** 가 왜 필요한지 동기를 얻습니다.

---

## 사전 조건

- Claude 챗봇 사용 경험 (claude.ai 웹 또는 Claude Desktop 앱)

---

## 절차

### 1. 같은 질문을 새 대화에서 3번 반복

Claude 챗봇을 열고, **새 대화**를 시작해 다음 prompt를 입력합니다. 답을 받은 뒤 **새 대화**(이전 대화 닫기)로 동일 prompt를 한 번 더, 또 한 번 더 ― 총 3회 반복합니다.

```
오늘 서울 날씨 어때?
```

> 반드시 매번 **새 대화**에서 시작하세요. 같은 대화 안에서 반복하면 이전 맥락이 영향을 줍니다.

### 2. 답을 한 번에 비교

3개 답을 위에서 아래로 늘어놓고 다음을 비교합니다.

| 비교 항목 | 1회차 | 2회차 | 3회차 |
|---------|-------|-------|-------|
| 답 길이 (대략 줄 수) | | | |
| 항목 순서 (온도·체감·바람·습도·미세먼지·우산…) | | | |
| 단위 표기 (°C / 섭씨 / 둘 다) | | | |
| 이모지 사용 여부 | | | |
| 우산·옷차림·미세먼지 안내 포함 여부 | | | |

### 3. 같은 질문을 prompt만 다르게 다시

이번엔 표현을 약간 바꿔 봅니다.

```
서울 오늘 날씨 알려줘.
```

```
오늘 비 와?
```

```
오늘 우산 챙겨야 해?
```

답이 어떻게 달라지는지 보세요. **사람에게 같은 의도로 묻는 표현**인데도 답의 폭이 더 커집니다.

---

## 관찰 포인트

- **형식 변동**: 같은 질문, 같은 모델, 같은 시점인데도 답의 구성이 매번 다르다.
- **누락·추가**: 어떤 답엔 우산 안내가 있고 어떤 답엔 없다.
- **표기 흔들림**: 단위·이모지·소제목 사용이 일관되지 않다.

> 이 흔들림이 한두 번은 괜찮지만, **매일·매주 반복되는 작업**이라면 매번 결과를 손으로 다듬어야 하는 비용이 누적됩니다.

---

## 정리

- 자유응답 챗봇은 **탐색·일회성** 질문에 강하지만 **형식 일관성**은 보장하지 않습니다.
- 다음 stage 2에서는 같은 질문에 **항상 동일한 형식**으로 답하도록 Skill을 만들어 봅니다.
