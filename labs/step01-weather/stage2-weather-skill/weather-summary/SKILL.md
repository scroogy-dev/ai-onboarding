# 날씨 한 줄 요약 Skill

사용자가 도시 이름(또는 위치)을 알려주면 그 도시의 오늘 날씨를 **아래 형식만** 사용하여 답한다.

## 출력 형식

다음 9줄을 정확히 이 순서·형식으로 출력한다. 다른 표현이나 부연 설명은 절대 추가하지 않는다.

```
🌡 **온도**: <숫자>°C
🤔 **체감**: <추움/선선/쾌적/더움/매우 더움 중 하나>
☁ **날씨**: <맑음/구름조금/구름많음/흐림/비/소나기/천둥번개/눈/안개 중 하나>
💨 **바람**: <약함/보통/강함> (<m/s 또는 km/h 수치>)
💧 **습도**: <숫자>% (<건조/적정/높음 중 하나>)
😷 **미세먼지(PM10)**: <좋음/보통/나쁨/매우 나쁨 중 하나>
😷 **초미세먼지(PM2.5)**: <좋음/보통/나쁨/매우 나쁨 중 하나>
☂ **우산 필요?**: <예 / 아니오> (<짧은 한 줄 이유>)
👕 **옷차림**: <한 줄 권고>
```

## 규칙

- 인사말, 추가 설명, 부연 표현은 모두 금지한다.
- 항목의 추가·삭제·순서 변경은 모두 금지한다.
- 모든 출력은 한국어로 한다.
- 도시를 명시하지 않으면 사용자에게 한 줄로만 다시 묻는다 (예: "어느 도시 날씨를 알려드릴까요?").
- 모델이 실시간 날씨 데이터에 접근할 수 없는 경우에도 형식은 유지하되, 출력 마지막 줄에 한 줄로 그 사실을 짧게 알린다 (예: "_(실시간 데이터 미연결, 일반적인 계절 추정값)_").

## 호출 예시

사용자: `서울`

기대 출력:
```
🌡 **온도**: 20°C
🤔 **체감**: 쾌적
☁ **날씨**: 맑음
💨 **바람**: 보통 (4 m/s)
💧 **습도**: 55% (적정)
😷 **미세먼지(PM10)**: 보통
😷 **초미세먼지(PM2.5)**: 좋음
☂ **우산 필요?**: 아니오 (강수 확률 낮음)
👕 **옷차림**: 얇은 긴팔이나 가벼운 가디건 권장
```
