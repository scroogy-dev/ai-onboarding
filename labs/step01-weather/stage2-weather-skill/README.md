# stage 2 — 정형 텍스트 응답 Skill (날씨)

> 자유응답으로 흔들리던 "오늘 날씨 어때?"의 답을, **항상 동일한 형식**으로 받아내도록 Agent Skill을 만듭니다.

---

## 학습 목표

- Agent Skill이 **"한 번 정의하고 반복 호출"** 하는 자산이라는 점을 체감합니다.
- Instructions에 **고정 출력 템플릿**을 명시하면 답의 형식이 어떻게 안정되는지 stage 1 결과와 비교합니다.

---

## 사전 조건

- [stage 1](../stage1-weather-prompt/) 수료 (자유응답의 흔들림을 직접 본 상태)
- Claude Pro 이상 요금제 (Skills 기능 사용에 필요)
- **Claude Desktop**에 Skill을 설치할 수 있는 환경

> **📌 Skill 설치 가이드는 별도 페이지에서 다룰 예정입니다.**
> 본 step은 "Skill을 Claude Desktop에 설치한 상태"로 가정하고 진행합니다.
> Claude Code(CLI) 사용자를 위한 설치 방법도 별도 페이지에서 짧게 함께 안내합니다.

---

## Agent Skill이란?

> 한 줄 요약: **"이 작업은 항상 이렇게 처리해줘"** 라고 미리 정의해 두고 호출하면, Claude가 그 정의대로 답하는 재사용 자산입니다.

자유응답이 "매번 처음부터 시키기"라면, Skill은 **"한 번 만들어 놓고 호출하기"** 입니다. 본 교육 [3단계 모델](https://scroogy-dev.github.io/ai-onboarding/#stage-model)의 2단계 핵심 도구입니다.

---

## 절차

### 1. 새 Skill 생성

Claude(웹 또는 Desktop)의 Skills 메뉴에서 **새 Skill 만들기**를 선택합니다.

| 항목 | 예시 입력값 |
|------|-----------|
| 이름 | `날씨 한 줄 요약` |
| 설명 | `도시 이름을 받아 오늘 날씨를 항상 같은 형식으로 답한다` |

### 2. Instructions에 고정 출력 템플릿 넣기

다음 내용을 Instructions에 붙여넣습니다.

```
역할: 사용자가 도시 이름(또는 위치)을 알려주면, 그 도시의 오늘 날씨를 아래 형식으로 답한다.

출력 형식 (이 형식만 사용, 다른 표현 금지):

🌡 **온도**: <숫자>°C
🤔 **체감**: <한 단어 — 추움/선선/쾌적/더움/매우 더움 중>
☁ **날씨**: <다음 중 하나 — 맑음/구름조금/구름많음/흐림/비/소나기/천둥번개/눈/안개>
💨 **바람**: <약함/보통/강함> — <m/s 또는 km/h 수치>
💧 **습도**: <숫자>% — <한 단어 — 건조/적정/높음 중>
😷 **미세먼지(PM10)**: <한 단어 — 좋음/보통/나쁨/매우 나쁨 중>
😷 **초미세먼지(PM2.5)**: <한 단어 — 좋음/보통/나쁨/매우 나쁨 중>
☂ **우산 필요?**: <예 / 아니오> — <짧은 한 줄 이유>
👕 **옷차림**: <한 줄 권고>

추가 설명, 인사말, 부연 표현, 항목 추가·삭제·순서 변경은 모두 금지한다.
도시를 명시하지 않으면 사용자에게 한 줄로 다시 묻는다.
```

> 이 instructions가 **"형식 흔들림"의 원인을 모두 잠그는** 역할을 합니다.

### 3. Skill 저장 후 호출

Skill을 저장하고, 새 대화에서 호출해 다음 prompt를 던집니다.

```
서울
```

```
부산
```

```
오늘 어때
```

(마지막 prompt는 도시가 빠진 케이스 — instructions의 "도시를 명시하지 않으면 다시 묻는다"가 동작하는지 확인)

### 4. stage 1과 비교

stage 1에서 받은 자유응답 3개와 이번 Skill 호출 3개를 늘어놓고 비교합니다.

| 비교 항목 | stage 1 (자유응답) | stage 2 (Skill) |
|---------|------------------|----------------|
| 답 길이 변동 | 매번 다름 | 거의 동일 |
| 항목 구성 | 매번 다름·일부 누락 | 항상 9줄 (온도·체감·날씨·바람·습도·PM10·PM2.5·우산·옷차림) |
| 단위·이모지 | 들쭉날쭉 | 고정 |
| 미세먼지·옷차림 누락 | 자유응답에선 자주 빠짐 | 항상 포함 |

---

## 관찰 포인트

- **같은 prompt에 같은 형식 답**이 나오는 게 핵심입니다. 내용(온도 숫자 등)은 시점·정보 출처에 따라 달라질 수 있어도, **표 모양은 흔들리지 않습니다**.
- Instructions 한 단락만 잘 적어도 형식 안정성이 크게 올라갑니다. 학습 도구를 만들 때도 같은 패턴이 그대로 통합니다.

---

## 트러블슈팅

| 증상 | 점검 |
|------|------|
| 형식이 그대로 안 나오고 부연이 붙는다 | Instructions에 "추가 설명·인사말 금지"가 빠지지 않았는지 확인 |
| 도시 없는 prompt에 임의로 서울로 답한다 | "도시를 명시하지 않으면 다시 묻는다" 규칙이 instructions에 있는지 |
| 정보가 부정확하다 | 모델은 실시간 날씨 API를 호출하지 않습니다. 이번 stage는 **형식 일관성**이 학습 목표 — 정확한 실시간 값은 stage 3에서 외부 데이터 연동 또는 사용자가 입력하는 형태로 다룹니다. |

---

## 막혔다면 — 동작 가능한 참고 Skill

본 stage의 동작하는 Skill은 [`weather-summary/SKILL.md`](./weather-summary/SKILL.md)에 그대로 들어 있습니다.

- 따라하다 막혔거나 결과 형식이 흔들릴 때, 위 파일의 instructions를 그대로 복사해서 본인 Skill의 instructions에 붙여 넣어 비교해 볼 수 있습니다.
- Claude Desktop의 Skills에서 해당 디렉토리를 그대로 등록해 직접 호출해 볼 수도 있습니다.
