# 날씨 HTML 리포트 Skill

사용자가 도시를 입력하면 본 Skill에 포함된 HTML 템플릿에 오늘 날씨를 채워 넣어 **파일 산출물**로 저장한다.

## 순서

### 1. 오늘 날씨 정리

다음 항목으로 정리한다 (stage 2 weather-summary Skill의 출력 형식과 동일).

- **온도**: 예 `20°C`
- **체감**: 한 단어 — 추움/선선/쾌적/더움/매우 더움
- **날씨**: 다음 중 하나 — `맑음/구름조금/구름많음/흐림/비/소나기/천둥번개/눈/안개`
- **바람**: `약함/보통/강함` + ` — ` + m/s 또는 km/h 수치
- **습도**: `<숫자>%` + ` — ` + `건조/적정/높음`
- **미세먼지 PM10**: `좋음/보통/나쁨/매우 나쁨`
- **초미세먼지 PM2.5**: `좋음/보통/나쁨/매우 나쁨`
- **우산 필요?**: `예` 또는 `아니오` + ` — ` + 짧은 이유
- **옷차림**: 한 줄 권고
- **한 줄 총평**: 외출 시 참고할 만한 한 문장

### 2. 템플릿 파일 읽기

본 Skill에 포함된 `weather-template.html` 파일을 읽는다. 작업공간이 아니라 **본 Skill의 리소스**에서 읽는다.

### 3. 슬롯 치환

템플릿의 다음 슬롯을 위에서 정리한 값으로 정확히 치환한다.

| 슬롯 | 값 |
|------|----|
| `{{city}}` | 사용자가 입력한 도시 |
| `{{date}}` | 오늘 날짜 — `YYYY-MM-DD (요일)` 형식 (예: `2026-05-08 (금)`) |
| `{{temperature}}` | 온도 — `20°C` 같은 형식 (heroes는 `20°` 큰 글자로 표시되므로 `°C` 단위 포함) |
| `{{feels_like}}` | 체감 한 단어 |
| `{{weather}}` | 날씨 한 단어 (정확히 9가지 중 하나 — 그래야 템플릿 내장 JS가 자동으로 알맞은 아이콘을 표시함) |
| `{{wind}}` | 바람 |
| `{{humidity}}` | 습도 |
| `{{pm10}}` | 미세먼지 PM10 등급 (좋음/보통/나쁨/매우 나쁨 — 템플릿 JS가 색상 자동 매핑) |
| `{{pm25}}` | 초미세먼지 PM2.5 등급 |
| `{{umbrella}}` | 우산 필요? |
| `{{clothing}}` | 옷차림 권고 |
| `{{summary}}` | 한 줄 총평 |

### 4. 새 파일로 저장

치환된 결과를 `weather-report-<도시>-<YYYY-MM-DD>.html` 파일명으로 작업공간에 새로 저장한다.

### 5. 사용자에게 안내

저장된 파일의 경로를 사용자에게 알린다 (예: "`weather-report-서울-2026-05-08.html` 파일을 작업공간에 저장했습니다.").

## 규칙

- 슬롯 이름과 매칭되지 않는 추가 텍스트는 절대 템플릿에 끼워 넣지 않는다.
- 슬롯이 그대로 `{{...}}`로 남는 일이 없도록 한다 — 모든 슬롯은 빠짐없이 채운다.
- 9가지 날씨 값(맑음·구름조금·구름많음·흐림·비·소나기·천둥번개·눈·안개) 외 다른 표현은 사용하지 않는다 (HTML이 자동으로 알맞은 아이콘을 매칭하므로).
- 미세먼지 등급도 4가지(좋음·보통·나쁨·매우 나쁨) 외 다른 표현 금지 (배지 색상 자동 매핑).
- 도시를 명시하지 않으면 한 줄로 다시 묻는다.
- 실시간 데이터에 접근할 수 없는 경우에도 형식과 절차는 유지하고, 사용자 안내 문구에 한 줄로 그 사실을 함께 알린다.

## 포함 파일

- `weather-template.html` — 슬롯이 포함된 HTML 템플릿. 네이버 날씨 스타일의 9가지 날씨 아이콘과 미세먼지 색상 배지가 내장되어 있어, 위 슬롯만 정확히 채우면 자동으로 알맞은 아이콘·색상이 표시된다.

## 호출 예시

사용자: `서울`

기대 동작:
1. 오늘 서울 날씨를 9개 항목으로 정리
2. `weather-template.html` 읽기
3. 슬롯 치환
4. `weather-report-서울-2026-05-08.html`로 작업공간에 저장
5. "서울 날씨 리포트를 `weather-report-서울-2026-05-08.html` 파일로 저장했습니다." 안내
