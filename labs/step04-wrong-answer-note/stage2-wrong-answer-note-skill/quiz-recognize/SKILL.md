# 채점지 인식 Skill

채점된 학습지 사진을 받아 문항 단위로 표(엑셀)로 정리한다. **정오 판정·정답 추론·해설은 하지 않는다**. 인식 결과를 사용자가 검수한 뒤 별도 Skill에서 채점·정리한다. 한 사진의 한 줄을 다시 인식하더라도 이미 다듬은 채점·해설이 흔들리지 않게 하기 위함이다.

## 입력값

| 입력 | 형태 |
|------|------|
| 학습지 사진 | 이미지 파일 첨부(PNG/JPG 권장). 채점 결과(연필 답안·채점 기호·자체 표시 포함)가 보이는 상태 |
| 학년 | 메타데이터에 기록할 정수 (예: `4`) |
| 과목 | 메타데이터에 기록할 문자열 (예: `수학`) |
| 단원 | (선택) 문자열(예: `분수의 덧셈과 뺄셈`) |
| 문제집 단축명 | (선택) 출력 파일명에 사용 (예: `최상위수학6-1`). 미지정이면 `quiz` |

사진 미첨부면 한 줄로 답한다: `학습지 사진을 첨부해 주세요.`
학년 또는 과목이 누락되면 한 줄로 다시 묻는다: `학년과 과목을 알려주세요.`

## 처리 단계

### 1단계 ― 인식 (정오 판정 금지)

사진의 모든 문항을 빠짐없이 읽어내되, 다음 규칙을 절대 어기지 않는다.

- 문항 번호 순서대로 모든 행을 만든다.
- 문제 내용은 사진에 적힌 텍스트를 **그대로** 옮긴다 (요약·재표현 금지).
- 학생이 연필로 적은 답안·표시도 모두 인식한다.
- 학생답안에 줄을 그은 흔적이 있으면 학생답안에는 그대로 남기고, 분석메모에 `줄 그음` 또는 `정정 흔적`을 적는다.
- 별표(★, *), 물음표(?), 동그라미(○) 같은 학생 자체 표시가 있으면 학생표시 컬럼을 1로 둔다 (정오와 무관).
- 채점 기호(O, X, △, V)와 학생답안이 명백히 충돌하면 분석메모에 `채점기호와 답안 충돌: <기호> vs <답안>`을 적는다.
- **정답 컬럼은 사진에 정답이 명시적으로 보일 때만 채운다**. 사진에 정답이 없으면 비워 둔다 (AI 추론 금지).
- **정오 컬럼은 비워 둔다**. 다음 단계 검수 후 별도 Skill이 처리한다.

### 2단계 ― 엑셀(또는 CSV) 저장

작업공간에 다음 컬럼 구조의 파일을 저장한다.

| 컬럼 | 내용 |
|------|------|
| 문항번호 | 정수 |
| 유형 | `객관식` / `단답형` / `서술형` / `계산` / `빈칸` / `연결` / `기타` |
| 문제내용 | 사진의 문제 텍스트 그대로 |
| 학생답안 | 학생이 적은 답 (연필·줄 그음 포함) |
| 정답 | 사진에 적혀있을 때만 채움. 없으면 빈 칸 |
| 학생표시 | `1` / `0` (별표 등 자체 표시 여부) |
| 정오 | **항상 빈 칸** (다음 Skill이 채움) |
| 개념태그 | 쉼표로 구분된 1~3개 키워드 (예: `통분, 분수의 덧셈`) |
| 분석메모 | 줄 그음·채점기호 충돌·인식 의문 등 |

상단에 메타데이터 시트(또는 첫 5행)를 둔다.

| 항목 | 값 |
|------|------|
| 분석일 | `YYYY-MM-DD` (오늘) |
| 학년 | 입력값 |
| 과목 | 입력값 |
| 단원 | 입력값(있으면) |
| 문제집_단축명 | 입력값 또는 `quiz` |
| 총문항수 | 인식된 문항 수 |
| 요주의수 | 학생표시가 1인 행 수 |
| 분석신뢰도 | `높음` / `보통` / `낮음` (인식 자신도) |

파일명: `quiz-recognized-<문제집_단축명>-<YYYY-MM-DD>-P<첫페이지>.xlsx`
첫페이지가 식별되지 않으면 `P00`으로 둔다.

> 사용자 환경이 엑셀을 만들기 어려우면 `.csv`로 저장한다 (확장자만 차이, 컬럼은 동일).

### 3단계 ― 응답

저장된 파일 경로와 다음을 한 줄로 알려준다.

```
인식 완료. <경로>
총 <N>문항, 학생표시 <M>건. 검수 후 자녀 오답노트 Skill을 호출하세요.
```

채점·해설은 하지 않는다. 사용자가 추가로 "채점도 해줘"라고 해도 한 줄로 거절한다.

```
채점은 검수 후 별도 Skill(`자녀 오답노트`)에서 진행합니다. 엑셀의 학생답안·정답·학생표시를 먼저 확인해 주세요.
```

## 호출 예시

사용자(사진 첨부 + 텍스트):

```
[학습지 사진]
4학년 수학, 단원: 분수의 덧셈과 뺄셈. 인식해줘.
```

기대 출력:

```
인식 완료. quiz-recognized-quiz-2026-05-09-P12.xlsx
총 10문항, 학생표시 2건. 검수 후 자녀 오답노트 Skill을 호출하세요.
```

검수 중 한 줄 재인식 요청:

```
3번 학생답안이 비어있는데 사진을 보면 자녀가 "5/12"라고 적었어. 그 행만 다시 채워줘.
```

기대 동작: 엑셀의 3번 행만 학생답안을 `5/12`로 갱신하고 분석메모에 `재인식: 학생답안 보강`을 추가한다. 다른 행은 건드리지 않는다.

## 추가 규칙

- 인사말·격려·해설을 출력하지 않는다.
- 사진의 글자 일부를 못 읽으면 그 셀은 비워 두고 분석메모에 `인식 의문`을 적는다 (추측 금지).
- 같은 사용자가 같은 사진을 다시 인식 요청하면 새 파일을 만들지 않고 기존 파일을 갱신한다(파일명 동일).

본 Skill의 핵심은 **인식과 정리의 경계를 엄격히 지키는 것**이다. 정오 판정·해설로 넘어가는 순간 사용자의 검수 자리가 사라진다.
