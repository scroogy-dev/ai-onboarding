# 자녀 오답노트 Skill

`quiz-recognize` Skill이 만들고 사용자가 검수한 엑셀을 입력으로 받아, 자녀가 스스로 읽고 이해할 수 있는 오답노트 마크다운을 생성한다. 자녀가 외운 풀이와 다르지 않게, 외울 만한 한 문장으로 끝맺는 형식을 따른다.

## 입력값

| 입력 | 형태 |
|------|------|
| 검수된 엑셀(또는 CSV) | 파일 첨부 또는 작업공간 파일 경로 |
| 정답 표 | (선택) 엑셀의 정답 컬럼이 비어있을 때 사진·텍스트로 보강 |
| 학년 | 정수(예: `4`) ― 엑셀 메타데이터에 있으면 그 값 사용 |
| 과목 | 문자열(예: `수학`) ― 동일 |
| 단원 | (선택) 헤더 라벨용 |

엑셀 미첨부면 한 줄로 답한다 ― `검수가 끝난 채점 결과 엑셀을 첨부해 주세요.`

## 처리 단계

### 1단계 ― 정오 판정 (검수된 엑셀 + 정답 표 기반)

다음 규칙을 적용해 각 행의 정오를 결정한다.

- 학생답안이 비어있으면 `정오: false`, 오답유형: `미기재`.
- 정답 컬럼이 채워져 있고 학생답안과 글자 단위로 일치하면 `정오: true`.
- 정답 컬럼이 비어있으면 첨부된 정답 표(또는 학년·교과 지식)에서 정답을 찾고 비교한다 ― 못 찾으면 `정오: false`, 분석메모에 `정답 미상`을 적는다.
- 학생답안에 정정 흔적이 있어 두 답이 보이면 **마지막에 적은 답**을 기준으로 비교한다 (분석메모 참고).
- 채점기호와 답안이 충돌하면 답안 데이터를 우선하고 분석메모에 그 사실을 한 줄 적는다.

### 2단계 ― 처리 범위 결정

다음 두 경우만 오답노트에 포함한다.

- `정오: false` 인 모든 문항
- `학생표시: 1` 인 모든 문항 (정답이어도 포함)

`정오: true` 이고 `학생표시: 1` 인 항목은 제목 옆에 `(스스로 체크)` 라벨을 붙인다.

### 3단계 ― 자녀용 오답노트 생성

다음 구조로 마크다운을 출력한다. 학년 정보를 보고 그 학년이 혼자 읽어도 이해할 수 있는 말투·용어로 쓴다.

```
**[과목] <과목> | [단원] <단원> | <YYYY-MM-DD>**

---

#### 문제 N번 (스스로 체크 ― 해당 시)

**문제:** <문제내용 그대로>

**내가 쓴 답:** <학생답안>
**맞는 답:** <정답>

**왜 헷갈렸을까?**
(오답유형·분석메모를 참고해 아이가 어떻게 생각했는지 공감하는 말로 시작.
 예: "분모끼리 더하면 된다고 생각했구나. 그런데 사실은…")
틀린 이유를 한두 문장으로 쉽게 설명한다.

**이렇게 풀어 보자**
1. (단계 1 ― 짧고 명확하게)
2. (단계 2)
3. …

**기억 포인트**
(이 문제의 핵심을 한 문장으로. "앞으로는 ~할 때 꼭 ~을 기억하자" 형식 권장)

---

(다음 문항 반복)

### 오늘의 복습 포인트

- 오늘 챙길 문제: **<N>문제** (<번호 목록>)
- 나온 개념: <개념 태그 모음>
- 가장 많은 오답 유형: **<유형>** ― <한 줄 코멘트>
- <격려 한마디 ― 자신감을 주는 말로>
```

### 말투·용어 규칙

- 친근하고 따뜻하게. `~했구나`, `~해 보자`, `잘 기억해 두자` 같은 말투.
- `틀렸다`, `실수했다`를 반복해서 강조하지 않는다.
- 어려운 개념어는 괄호 안에 짧게 풀어쓴다 (예: `통분(분모를 같게 만들기)`).
- 풀이가 너무 길어지지 않게 한다. 한 문항에 단계 5개 이내가 적정.
- 학년에 맞춘 어휘 ― 저학년(1~2)은 더 짧게·더 쉽게, 고학년(5~6)은 좀 더 자세히.

### 4단계 ― 응답

마크다운 본문을 화면에 출력하고, 동일 본문을 작업공간 파일로도 저장한다.

파일명: `wrong-answer-note-<과목>-<YYYY-MM-DD>.md`

```
오답노트 작성 완료. <경로>
오늘 챙길 문제 <N>건, 스스로 체크 <K>건.
```

## 호출 예시

사용자:

```
[검수된 엑셀 첨부]
이 엑셀로 자녀 오답노트 만들어줘. 학년 4학년, 과목 수학, 단원 분수의 덧셈과 뺄셈.
```

기대 출력 (마크다운 본문 + 저장 경로 한 줄):

```
**[과목] 수학 | [단원] 분수의 덧셈과 뺄셈 | 2026-05-09**

---

#### 문제 1번

**문제:** 1/3 + 1/4 = ?

**내가 쓴 답:** 2/7
**맞는 답:** 7/12

**왜 헷갈렸을까?**
분자는 분자끼리, 분모는 분모끼리 더하면 된다고 생각했구나. 그렇게 느껴지는 게 당연해. 그런데 분모가 다른 분수를 더할 땐 먼저 분모를 같게 만들어 줘야 해.

**이렇게 풀어 보자**
1. 3과 4의 공통 분모를 찾는다 → 3과 4의 최소공배수는 **12**
2. 1/3을 분모 12로 바꾼다 → 1/3 = 4/12
3. 1/4를 분모 12로 바꾼다 → 1/4 = 3/12
4. 분모가 같으니 분자끼리만 더한다 → 4/12 + 3/12 = **7/12**

**기억 포인트**
분모가 다른 분수를 더하거나 뺄 땐 **통분(분모를 같게 만들기)** 을 꼭 먼저 하자.

---

### 오늘의 복습 포인트

- 오늘 챙길 문제: **2문제** (1번, 3번)
- 나온 개념: 통분, 분수의 덧셈
- 가장 많은 오답 유형: **개념오해** ― 풀이 방법 자체를 다시 한 번 확인하면 좋아
- 오늘 틀린 문제들, 이제 왜 그랬는지 알았지? 한 번 더 풀어보면 다음엔 꼭 맞출 수 있을 거야.

오답노트 작성 완료. wrong-answer-note-수학-2026-05-09.md
오늘 챙길 문제 2건, 스스로 체크 0건.
```

## 추가 규칙

- 메타데이터(분석일·학년·과목)는 입력 엑셀에서 우선 가져오고, 사용자가 호출 prompt에 따로 적은 값이 있으면 그 값으로 덮어쓴다.
- 사용자가 "더 짧게", "1학년이 읽을 수 있게" 같이 후속 호출하면 **출력 톤만** 다시 만든다 (정오 판정·문항 선택은 그대로).
- 정답을 결정할 수 없는 문항은 오답노트에서 제외하고 응답 끝에 한 줄로 안내한다 ― `<번호 목록> 문항은 정답 미상으로 제외했습니다. 정답 표를 같이 첨부해 주세요.`

본 Skill의 핵심은 **자녀가 외울 한 문장(기억 포인트)** 까지 챙기는 것이다. 인식·검수는 앞 Skill이 잡아 주므로 본 Skill은 자녀의 학습 효익에만 집중한다.
