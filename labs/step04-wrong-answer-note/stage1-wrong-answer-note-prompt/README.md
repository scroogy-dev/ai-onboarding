# stage 1 ― 챗봇 자유응답 (사진 한 장으로 오답노트 시도)

> 자녀가 풀고 채점한 학습지 사진 한 장에 **인식·채점·해설·정리**를 한 번에 시켰을 때, OCR 오인식과 출력 형식이 어떻게 흔들리는지 체감합니다. 특히 **인식이 틀렸을 때 다시 처음부터 시켜야 하는** 재인식 비용이 큰 이유를 직접 봅니다.

---

## 학습 목표

- 같은 사진·같은 요청을 반복해도 챗봇이 **연필 답안·줄 그은 부분을 매번 다르게** 인식하는 흔들림을 관찰합니다.
- 출력 형식(문항 정리·해설 깊이·말투)이 회차마다 달라지는 것을 직접 봅니다.
- "한 번에 인식·채점·해설까지" 가버리는 자유응답이, 인식이 어긋났을 때 **다시 처음부터 사진 분석**을 시키는 비용을 만든다는 것을 체감합니다.
- stage 2에서 왜 인식 단계와 정리 단계를 **일부러 쪼개는지** 동기를 얻습니다.

---

## 사전 조건

- Claude 챗봇 사용 경험 (claude.ai 웹 또는 Claude Desktop)
- **이미지 업로드가 가능한 환경**
- 자녀가 풀고 채점된 학습지 사진 1장 ― 또는 본인이 풀고 직접 채점한 임의 학습지 사진

> **사진을 준비할 때**: 가능하면 **연필로 적은 답안**·**줄 그은 부분**·**별표(★)나 물음표(?) 같은 자체 표시**가 한두 군데 섞인 사진을 고르세요. 이런 요소가 있어야 stage 1의 흔들림이 더 뚜렷하게 드러납니다.

---

## 절차

### 1. 같은 사진을 새 대화에서 3번 반복 요청

Claude 챗봇을 열고, **새 대화**에서 학습지 사진을 업로드한 뒤 다음 prompt를 입력합니다.

```
이 사진은 자녀가 풀고 채점한 학습지야. 자녀가 혼자 읽을 수 있는 오답노트로 정리해줘.
```

답을 받은 뒤 **새 대화**(이전 대화 닫기)에서 동일 사진·동일 prompt를 두 번 더 반복합니다 ― 총 3회.

> 반드시 매번 **새 대화**에서 시작하세요. 같은 대화 안에서 반복하면 이전 맥락이 영향을 줍니다.

### 2. 답을 늘어놓고 비교

3개 답을 위에서 아래로 두고 다음을 비교합니다.

| 비교 항목 | 1회차 | 2회차 | 3회차 |
|---------|-------|-------|-------|
| 연필로 적은 답안이 학생답안으로 잡혔는지 | | | |
| 줄 그은 부분이 어떻게 처리됐는지 (틀린 답으로 / 무시 / 정상 인식) | | | |
| 별표·물음표 같은 자체 표시가 인식됐는지 | | | |
| 채점이 자동으로 됐는지 (정/오 판정) | | | |
| 정답이 어디서 왔는지 (사진 / AI 추론 / 비어있음) | | | |
| 해설의 깊이·톤 (한 줄·여러 단계·친근한 말투 여부) | | | |
| 출력 구조 (제목·헤더·항목 순서) | | | |
| 자녀 학년 수준 용어 사용 여부 | | | |

특히 **연필 답안 인식**과 **줄 그은 부분 처리**가 회차마다 가장 많이 흔들리는 항목입니다.

### 3. 인식이 틀렸을 때를 시뮬레이션

3회차 답 중 인식이 틀린 항목을 골라 그 대화 안에서 다시 요청해 보세요.

```
3번 문제는 자녀가 연필로 답을 적었는데 너가 비어있다고 했어. 다시 봐줘.
```

답이 어떻게 돌아오는지 보면서 다음을 관찰합니다.

- 사진을 다시 분석하느라 답이 길어지는지
- 3번만 다시 보는 게 아니라 **다른 문항의 채점·해설까지 다시 풀어 쓰는지** (재인식이 한 항목으로 끝나지 않는 경향)
- 결과적으로 1회차에 받았던 다른 문항 해설을 폐기하고 새로 받게 되는지

이게 자유응답에서 **재인식 비용**이 커지는 이유입니다 ― 한 사진에 인식·채점·해설을 한 번에 묶어 처리했기 때문에, 인식 한 줄을 고치자고 해도 **모든 출력이 다시 흔들립니다**.

---

## 관찰 포인트

- **연필 답안 인식 실패**: 인쇄된 채점 기호(X, △)는 잘 읽지만, 자녀가 연필로 적은 학생답안은 자주 누락되거나 다른 글자로 읽힙니다.
- **줄 그은 부분 오인식**: 자녀가 연필로 정정하면서 줄을 그은 곳을 "틀린 답"으로 처리하거나, 반대로 정답으로 오인하는 경우가 섞여 있습니다.
- **자체 표시 누락**: 별표(★)·물음표(?)·동그라미는 자유응답에선 거의 무시됩니다 ― 정답인데 자녀가 헷갈렸다고 표시한 항목이 오답노트에 들어가지 않습니다.
- **자동 채점·해설로의 폭주**: 사용자가 "정리해줘"라고만 했는데 AI는 곧장 채점·해설·복습 시점까지 만들어 버립니다 ― 인식이 어긋났을 때 그 모든 후속 출력이 함께 어긋납니다.
- **출력 형식 매번 다름**: 어떤 회차는 표, 어떤 회차는 카드, 어떤 회차는 줄글 ― 자녀에게 매주 같은 형태로 주려고 하면 부모가 매번 다듬어야 합니다.

> 자녀 학습 보조 도구로 **매주·매학기 반복**해서 쓰려고 할 때, 인식 오류가 한 항목만 있어도 **모든 출력을 다시 받아야 한다**는 것이 본 step의 가장 큰 페인포인트입니다.

---

## 정리

- 자유응답 챗봇은 사진 한 장으로 **인식·채점·해설을 한꺼번에** 처리해 줍니다 ― 빠르고 한 번에 끝나는 것처럼 보입니다.
- 그러나 인식이 어긋날 때 **그 어긋남이 모든 후속 출력에 그대로 전이**되어, 한 줄을 고치려면 모든 출력을 다시 받아야 합니다.
- 다음 stage 2에서는 **인식 단계와 정리 단계를 일부러 쪼개고**, 그 사이에 **사람의 검수 자리**를 둡니다. 정형화의 진짜 가치가 형식 일관성 너머 **워크플로우 분할**에 있다는 것을 직접 만들어 봅니다.
